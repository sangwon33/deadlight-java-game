## 글자

- 작은 HUD 보조 글자를 크게 하고 체력/포션/지역 목표/스킬/메뉴 키 안내의 대비를 높였습니다.
- 폰트에 밝은 획 보강과 어두운 그림자를 적용해 얇고 흐려 보이는 글자를 개선했습니다.
- 화면 위에는 부드러운 연속 음영을 넣어 밝은 안개 배경에서도 읽히게 했습니다. 골드/포션마다 검은 사각 패널을 넣지는 않았습니다.
- 안내 글자의 크기와 줄 간격을 늘리고, 보조 색도 더 밝게 조정했습니다.
- 튜토리얼은 짧은 문장과 줄바꿈을 사용해 긴 문장이 작게 축소되지 않도록 했습니다.
- 적의 공격 준비/빈틈 표시와 화면 조작 키 이름도 키웠습니다.
- 한글 공통 배율과 소수 위치 렌더링을 유지하여 글자별 기준선이 어긋나지 않게 했습니다.
- 1280×720과 960×540 화면에서 메뉴와 HUD를 확인했습니다.

## 지도

1~3지역 오른쪽 위에 미니맵을 추가했습니다. Tab을 누르고 있으면 큰 탐색 지도가 열리며 게임은 기존처럼 일시정지합니다. Tab을 놓으면 닫힙니다.

지도는 현재 모험에서 실제로 지나간 주변 구역만 드러납니다. 아직 가지 않은 지하길이나 높은 발판은 빈 공간으로 남습니다. 발견하지 않은 바람 발판/승강기/문/출구 표시도 숨깁니다.

- 플레이어 위치 주변의 작은 영역을 64단위 탐색 셀에 기록합니다.
- 긴 바닥과 다리도 탐색한 셀에 속하는 부분만 잘라 그립니다.
- 승강기 경로를 발견했다고 전체 높이가 미리 드러나지 않도록 구간별로 표시합니다.
- 전체 지도는 탐색한 범위를 중심으로 크기를 조절하고, 미니맵은 현재 위치 주변을 보여줍니다.
- 지도 영역은 불투명하게 처리하여 뒤쪽 게임 지형이 비쳐 미탐색 지형으로 오해되지 않게 했습니다.
- 지나온 길이 떨어진 여러 구역으로 나뉘어 있어도 중간의 미탐색 구역을 자동으로 연결하지 않습니다.
- 같은 좌표라도 지역마다 탐색 기록을 따로 관리합니다.

## 탐색 기록 수명

현재 모험 안에서는 사망 후 지역 재도전을 해도 탐색한 지도를 유지합니다. 다음 지역으로 이동해도 이전 지역의 탐색 정보는 유지합니다.

새 모험이나 새 지역 연습을 시작하면 탐색 기록을 초기화합니다. 기존 게임에 모험 중간 저장 기능이 없으므로 탐색 지도도 앱 종료 후 복원하는 별도 저장 기능은 추가하지 않았습니다. 키 설정이나 기존 클리어 기록 데이터는 변경하지 않습니다.

## 코드

- ExplorationMap.java: 지역별 탐색 셀, 미니맵/전체 지도, 미탐색 지형과 표시 필터.
- Main.java: 새 모험 초기화, 지역 진입/이동 시 탐색 기록, 지도 표시 연결과 폰트 획 보강.
- WorldGimmicks.java: 전체 지형을 보여주던 이전 지도 렌더링 제거. 기믹 동작은 유지.
- UiTheme.java: 더 밝은 글자 색/그림자, 줄바꿈 문단, 매끄러운 상단 음영.
- GameHud/JourneyView/RegionGuide/TutorialGuide/GameControls/EnemyAttackView: 실제 글자 크기와 안내 영역 조정.

## 검증

실제 OpenGL 게임 창에서 자동 입력과 메모리 Preferences를 사용했습니다.

- Java/Gradle 컴파일 및 실제 렌더링 통과.
- 시작 위치만 방문했을 때 멀리 있는 긴 바닥이 표시되지 않는지 화면 픽셀 검사.
- 미발견 기믹이 있는 상태와 없는 상태의 지도 이미지를 비교하여 미탐색 표시가 새어 나오지 않음을 확인.
- 바람 발판을 발견하면 지도 표시가 나타나는지 확인.
- 실제 이동에 따라 탐색 영역 증가, 떨어진 두 방문 구역 사이의 미탐색 영역 유지 확인.
- 사망/재도전 기록 유지, 지역별 기록 분리, 새 모험 초기화 확인.
- 지도 중 플레이어와 승강기의 정지 확인.
- 튜토리얼 7과제의 실제 문구가 읽을 수 있는 크기 아래로 축소되지 않는지 렌더링 검사.
- 로비/설정/키 변경/HUD 가방과 일시정지/가방 포션 사용/메뉴 복귀 클릭 확인.
- 16종 UI 화면을 1280×720과 960×540에서 실제 렌더링하여 확인.
- 테스트에서 사용자 저장 설정/클리어 기록을 사용하거나 덮어쓰지 않았습니다.

일부 탐색/재도전 검사는 시작 위치와 적 상태를 직접 구성했습니다. 사람이 전 지역을 수동 완주한 검사는 아닙니다.
