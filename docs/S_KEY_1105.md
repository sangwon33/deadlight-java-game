# S 짧게/길게 통합 조작 — 2026-11-05

- 기본 S를 짧게 눌렀다 놓으면 현재 밟고 있는 얇은 발판/승강기 한 칸 아래로 내려갑니다. 짧은 입력은 키를 **놓는 순간** 확정합니다.
- 가만히 서서 S를 누르면 기존 hero-look.png의 전용 엎드린 에셋을 즉시 표시합니다. 원본 비율과 접지선을 유지하며 그림을 눌러서 만들지 않습니다.
- S를 0.65초 이상 유지하면 아래 지형을 살펴봅니다. 추가 대기 없이 0.65초 시점부터 카메라가 이동합니다. 자세 준비와 카메라 이동의 대기 시간을 분리했습니다.
- 길게 누른 뒤 놓으면 원래 시야로 부드럽게 돌아오고 발판에서 떨어지지 않습니다.
- 단단한 바닥은 통과하지 않으며, 한 번의 짧은 입력으로 여러 층을 연속 통과하지 않습니다.
- ↓의 기존 아래 보기와 ↓+점프 내려가기 조합은 제거했습니다. S와 함께 점프 키를 누르면 일반 점프를 하며 살펴보기를 취소합니다.
- 메뉴/지도/일시정지/피격/점프/공격 등으로 입력이 끊기면 짧은 누름을 취소하여, 나중에 키를 놓았을 때 갑자기 떨어지지 않게 했습니다.
- 공중에서 누른 S를 착지 후 내려가기로 예약하지 않습니다.
- 설정의 ‘내려가기 / 아래 보기’에서 통합 키를 변경합니다. 기존 기본 저장값 ↓는 최초 한 번 S로 이관하며 다른 행동 설정과 사용자 지정 통합 키는 유지합니다.
- 위 보기 W/↑, 기존 확대된 시야/캐릭터 프레임 여유, 방문한 곳만 표시하는 지도는 계속 적용됩니다.

## 구현 및 검증

DownGesture.java에서 짧은 입력과 긴 입력을 구분하고, Player에서 발판의 동일성/한 층 내려가기/전용 자세에 연결했습니다. CameraLook에는 긴 입력이 이미 완료됐다는 상태를 전달하여 대기 시간이 두 번 적용되지 않게 했습니다. 키 설정/튜토리얼/지역 안내도 새 조작으로 바꿨습니다.

실제 LWJGL/OpenGL 게임 창과 메모리 설정을 사용했습니다.

- 30/60/120fps의 짧은 누름, 0.65초 경계, 긴 누름, 반복 키 이벤트, 같은 프레임에 누르고 떼는 짧은 입력.
- 키를 떼기 전에는 내려가지 않음, 긴 누름에는 추가 0.65초 대기 없음, 긴 누름 해제 후 발판/승강기 유지.
- 한 층 내려가기, 단단한 바닥, 일반 점프, 메뉴/지도/일시정지/공격으로 취소한 뒤 불필요한 내려가기 방지.
- 저장된 ↓ 기본값 이관과 사용자 지정 키 유지/재설정.
- 새 S 조작으로 튜토리얼을 완료한 뒤 세 지역의 상층 경로/보급품, 수문장/출구, 상점/보상/재도전/보스 클리어 검사.
- 두 해상도(1280×720, 960×540)의 16개 UI 화면 및 클릭/키 설정 검사.
