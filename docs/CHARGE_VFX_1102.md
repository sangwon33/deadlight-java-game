# 차징 스킬 이펙트 강화

적용 프로젝트: `C:\Users\USER\Desktop\Java\Deadlight`

- 충전 단계별 흰색/하늘색/보라색/금색을 유지하고, 캐릭터 오라·발밑 회전 문양·무기로 모이는 나선 입자·상승하는 불씨를 추가했습니다.
- 3단계부터 짧은 전기 궤적을, 4단계에는 이중 광륜·맥동하는 빛·발밑으로 퍼지는 파동·중심 섬광을 추가했습니다. 단계가 바뀔 때는 고리가 한 번 퍼집니다.
- 키를 놓으면 단계 색상의 넓은 초승달 검기, 흰색 중심선, 끝의 섬광, 흩어지는 빛 조각과 회복 동작까지 남는 잔광이 나타납니다.
- 검기는 실제 공격 방향과 사거리를 기준으로 그리며, 잔광은 공격 당시의 월드 위치에 남습니다.
- 일시정지/모달 화면에서는 효과의 시간이 멈춥니다. 피격 취소나 새 플레이어/지역으로 바뀌면 이전 효과를 정리합니다.
- 빛은 로컬 가산 합성으로 표시하고, 그린 뒤 GL 블렌딩과 렌더러 색을 복원합니다. 프레임마다 입자 객체나 텍스처를 생성하지 않습니다.

변경 소스: `ShockSlashView.java`, `Main.java`. 충전 시간·피해·판정·재사용 대기시간은 유지합니다.

검증: 실제 OpenGL 실행으로 밝은 1지역/어두운 3지역의 네 단계와 좌/우 발동을 연속 렌더링했습니다. 잔광의 수명/위치, 일시정지, 피격, 지역 초기화, GL 상태 복구를 검사했고 OpenGL 오류 없이 통과했습니다. 기존 차징 조작·단계별 피해·1회 적중·쿨타임·키 변경·화면 버튼·튜토리얼·상점 키 자동 검사도 통과했습니다. 사용자 설정과 기록에는 메모리 테스트 Preferences를 사용했습니다.

`Deadlight_charge_vfx_1102.gif`는 실제 게임에서 캡처한 20fps 미리보기입니다. 통합 ZIP에도 변경을 반영했습니다. 실행 중인 게임을 닫고 Eclipse에서 F5 후 다시 실행하세요.
