# DeadLight 로비와 UI 개편 — 2026-11-04

C:/Users/USER/Desktop/Java/Deadlight 에 적용했습니다. 기존 은청색 손그림 배경에 맞춰 로비·플레이 HUD·일시정지·상점·가방·보상·결과·설정 화면의 UI를 정리했습니다. 캐릭터 에셋과 전투 수치는 변경하지 않았습니다.

## 로비

- 큰 사각형 버튼과 오른쪽 아래 기록 박스를 제거했습니다.
- 넓은 배경과 검객이 보이도록 왼쪽에 글자 메뉴를 배치했습니다.
- 은청색 가는 선과 마름모 장식, 작은 문구, 간결한 기록 요약을 사용합니다.
- 여정 시작 / 지역 선택 / 설정 / 게임 종료.
- 방향키 위·아래 또는 W/S로 선택하고 Enter로 실행합니다. 마우스 이동/클릭도 가능합니다.
- 선택한 항목에 작은 좌우 장식과 은은한 강조를 표시합니다.
- 기존 최고 기록/클리어 횟수를 하단 한 줄에 표시하며 기록 데이터는 유지합니다.
- 새 LobbyView.java에서 표시 영역을 정의하고 Main의 실제 클릭 판정도 같은 영역을 사용합니다.

## 플레이 HUD

- 큰 지역 목표 패널과 스킬 설명 패널을 없애고 글자와 얇은 선으로 정리했습니다.
- 체력은 숫자와 가는 은청색 바, 피격 시 남는 체력 변화 표시를 유지합니다.
- 골드와 포션 뒤에 큰 검은 패널을 추가하지 않았습니다.
- 가방/일시정지는 짧은 글자 버튼이며 커서를 올리면 장식과 강조가 나타납니다.
- 보스 체력도 상단 중앙의 가는 보랏빛 바와 숫자로 줄였습니다.
- 구간 안내의 높이와 글자 간격을 줄이고 마지막 줄과 테두리 간격을 확보했습니다.
- 작은 글자에는 얇은 어두운 외곽선을 적용해 밝은 안개 위에서도 읽히게 했습니다.
- 폰트의 공통 배율/소수 좌표 렌더링은 유지하여 이전 한글 기준선 수정이 유지됩니다.
- 화면 조작 버튼의 픽셀 아이콘을 얇은 선 아이콘으로 바꾸고 원형 장식과 채움도 가볍게 했습니다. 실제 입력 영역과 조작 기능은 유지합니다.

## 메뉴 계열

- 공통 UiTheme: 불투명한 전체 사각 테두리 대신 어두운 반투명 면, 가는 상하선, 작은 모서리 장식.
- 일시정지: 중앙 세로형 메뉴와 선 아이콘. 계속하기 / 처음부터 다시 / 설정 / 메인 메뉴. 재시작/메뉴 복귀 확인 단계와 Esc/Enter 동작 유지.
- 상점: '등불 아래의 상점', 품목별 가는 구분선, 장식 안의 새 아이템 이미지, 은청색 구매 표시. 가격·부족 금액·구매 완료·능력치 미리보기 유지.
- 가방: '여행자의 가방', 물약 장식과 얇은 구분선. 최대 체력에서는 회복 불가, 수량과 단축키/버프 시간 표시 유지.
- 보상: 선택한 카드에 작은 장식과 상단 강조. 선택과 Enter 확정은 기존처럼 분리.
- 결과: 통계 칸의 큰 면을 줄이고 가는 선과 글자로 표시. 요약/지역별 탭과 재도전/로비 기능 유지.
- 설정/키 설정/지역 선택: 공통 장식과 버튼 모양 반영. 자동 저장·키 교환·지역 미리보기 유지.

## 검증

실제 OpenGL 게임 창에서 자동 입력과 메모리 Preferences를 사용했습니다.

- Java/Gradle 컴파일 통과.
- 1280×720 및 960×540에서 16종 화면을 실제 렌더링하고 확인.
- 로비 마우스 시작과 방향키 선택/Enter 진입 확인.
- 설정 음량 버튼, 키 설정에서 행동 선택/새 키 입력 확인.
- HUD의 가방/일시정지 버튼, 가방의 회복 물약 사용/닫기 클릭 확인.
- 새 일시정지 메뉴에서 설정 진입 → Esc 복귀 → 계속하기 클릭 확인.
- 기존 튜토리얼 6과제, 상점/포션/체크포인트/지역 보상/실제 보스 전투 클리어/통계/기록/키 저장 검사 통과.
- 테스트에 실제 사용자 Preferences를 사용하지 않았으므로 사용자 설정과 기록을 변경하지 않았습니다.

스크린샷용 보유 골드/물약/지역 등은 테스트 상태를 구성했습니다. 모든 게임 구간을 사람이 수동 완주한 검사는 아닙니다.
