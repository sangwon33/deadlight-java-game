## 합친 기능

### 지상 평타 3타 콤보

기본 J를 다시 눌러 가로 베기 → 올려베기 → 전진 내려베기를 연결합니다. 한 번 누르면 1타만 실행하며 누르고 있기만 해서는 자동 연타하지 않습니다. 후속 입력은 한 개만 예약합니다. 기본 피해는 6 / 6 / 8이며 적의 빈틈에는 1.5배입니다. 3타는 20픽셀 전진하고 기사의 정면 방어를 뚫는 강공격입니다.

1·2타 중에는 즉시 대시 취소가 가능하고 3타는 0.30초 이후 가능합니다. 공중 일반 공격과 Q 돌진 찌르기는 기존 경로를 유지합니다. 피격·대시·사망 때 콤보를 취소하고 메뉴·포커스 변경 때 후속 입력을 비웁니다. 현재 키 설정과 화면 공격 버튼을 사용합니다.

새 9포즈와 6종 궤적, 명중 지점의 짧은 흰색 스파크를 연결했습니다. 원본 PNG와 프레임별 발 기준·공통 배율을 유지했습니다. 섬광 완화 설정을 켜면 새 평타 궤적/스파크를 숨기고 피격 점멸을 완화합니다.

### 최종보스

4지역의 최종보스를 대검을 든 **일식의 처형자**로 교체했습니다. HP 240, 피해 24 / 격화 28이며 가로 베기·내려찍기·올려베기·전진 베기를 사용합니다. 방향을 고정한 준비 동작과 공격 후 빈틈, 대시 무적, 평타/Q의 대상별 중복 타격 제한을 연결했습니다. 처치 동작 1.05초가 흐른 뒤 결과 화면으로 전환하며 마지막 타격의 히트스톱 시간은 별도입니다.

### 일반 적

가면 나방과 등불 사수를 합쳐 일반 지역의 적은 15 / 18 / 19마리입니다. 현재 맵 좌표로 환산하고 지상 적은 실제 발판/바닥 위에 배치했습니다. 나방은 준비 후 고정 방향으로 돌진하는 비행 적입니다. 사수는 조준 후 직선탄을 발사하고 지형에 가려지면 사격하지 않습니다. 화면 밖에서는 새 사격을 시작하지 않으며 남은 탄환은 지형·플레이어·수명으로 처리합니다. 기본 적의 지속 추격·순찰과 붉은 수문장의 크기 1.5배 / HP 54 / 피해 30을 유지했습니다.

## 현재 기능과 연결한 부분

- 설정 5탭/26항목·행동 키, S 짧게 내려가기/길게 엎드려 살펴보기, 카메라 경계와 UI 전용 카메라를 유지했습니다.
- 발견한 곳만 보이는 지도에 중간보스 방 입구를 추가했습니다. 방문 전에는 숨기고 방문 후 시련 이름, 처치 후 완료 색상을 표시합니다. 카메라로 보기만 해서는 발견되지 않습니다.
- 중간/최종보스에 체력 숫자와 피해 잔상을 연결했습니다. 상단 보스바가 지역 목표·길 안내와 겹치지 않게 정리하고, 월드 입구 문구가 가방/Esc 버튼과 겹치던 표시를 제거했습니다.
- 모든 새 타격·사격 소리가 전체/효과 음량과 창 포커스 음소거를 따릅니다. 새 평타 피격 피드백도 피해 숫자·섬광 완화·타격 멈춤 설정을 사용합니다. 실제 공격 탄환과 뿌리/바늘은 섬광 완화 중에도 보입니다.
- 허수아비 훈련장, 체력 100, 점프 990, 무너지는 다리·분출 함정·회복 우물·보급 가방/상자·스킬 준비 알림을 유지했습니다. 본편 기본 발판 40개에 선택 방 진입 발판 5/6/3개가 더해졌습니다.
- 최종 전투/맵 조합은 **rules7** 기록으로 분리하며 이전 rules6 및 팀원판의 과거 기록을 지우지 않습니다.
- 팀원판에서 아직 연결하지 않은 아래 베기는 새로 활성화하지 않았습니다. 관련 원본 에셋은 보존합니다.

## 검증

실제 LWJGL/OpenGL을 실행하고 격리한 메모리 설정·입력 프록시로 검증했습니다. 수동 플레이를 대신한 자동 검사이며 실제 사용자 설정/기록은 덮어쓰지 않았습니다.

- 30/60/120fps 콤보 단계·전진 20, 실제 Main 공격 경로의 6+6+8 각 1회 피해, 키 재설정·누른 상태·대시 취소, 기존 Q와 S 입력.
- 세 중간보스 전체 공격 패턴·회복/격화·영역 제한, 실제 점프 입력으로 방까지 이동, E 도전·봉인·평타 반격·보상 중복 방지·문 열림·재도전 복원.
- 실제 3타 공격으로 최종보스 처치, 사망 연출 뒤 결과 전환. 자동 전투 검사에서는 플레이어 무적을 사용해 피격 생존과 무관하게 공격/종료 경로를 검증했고, 공격 피해·대시 무적은 별도 검사했습니다.
- 새 적의 실제 배치/그리기/사망/골드, 지상 적의 발판, 사수의 사격·화면 밖 사격 제한·엄폐.
- 지도 픽셀 검사: 방문 전 시련/기믹 비공개, 방문 후 표시, 처치 완료 표시, 지형 발견·미탐색·재도전 유지/새 모험 초기화.
- 기존 피해 잔상·고정 허수아비·수문장·점프·스킬 준비·함정/우물/발판 검사, 30/60/120fps S 입력/엎드린 자세/승강기/메뉴 입력 초기화 검사.
- 설정 26항목 저장·초기화·포커스·실제 창 크기 변경·픽셀 반영 검사, 1280×720과 960×540/글씨 120%의 설정 및 기존 메뉴 렌더링.
- 공통 맵의 실제 바람/점프 경로와 높은 보급품 접근 검사.
- 7과제 튜토리얼부터 지역 보상·상점·중간보스 강화의 다음 지역 유지·최종보스·4지역 결과·rules7 기록까지 연결 검사. 기존 rules6 클리어 수/최고 시간 보존 확인.
