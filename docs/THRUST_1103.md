## 이번 버전

기존 발도술을 제거하고 2초 정신집중 후 자동으로 앞으로 돌진하면서 검으로 찌르는 스킬로 교체했습니다. 이번 단계는 새 캐릭터 자세를 확인하는 버전이며 스킬 전용 시각 효과와 오디오는 넣지 않았습니다.

- 기본 Q 또는 변경한 스킬 키/화면 버튼을 2초 유지합니다. 충전은 0~0.5 / 0.5~1 / 1~1.5 / 1.5~2초의 4단계이며 HUD에서 확인합니다.
- 집중 중 이동·점프·공격·대시·방향 전환을 막고 몸 가까이 검을 당겨 준비합니다. 1초부터 더 낮은 집중 자세로 바뀝니다.
- 2초가 지나면 바라보는 방향으로 자동 돌진하며 양손으로 검을 앞으로 찌릅니다.
- 임시 돌진 수치: 0.30초 동안 속도 700으로 210 게임 단위 이동. 맵 끝에서는 정지합니다. 총 돌진·회복 동작은 약 0.56초입니다.
- 임시 피해 20과 재사용 8초는 유지했습니다. 집중 중 일찍 놓으면 공격 없이 취소합니다. 피격 시에는 기존 취소 규칙을 적용합니다.
- 빠른 돌진 중에도 적을 빠뜨리지 않도록 이전 위치부터 현재 위치까지의 검 경로를 검사합니다. 각 적/보스는 한 번만 맞습니다. 타격 높이는 검끝 부근으로 좁혔습니다.
- 옛 칼집 빛, 오라, 입자, 검광, 충격파, 잔상, 카메라 진동, 가장자리 섬광, 전용 충전/발도음은 제거했습니다.
- 피해를 입은 적 자체의 기존 피격/사망 동작과 플레이어 피격 표시는 일반 전투 기능으로 유지합니다.
- HUD·키 설정·튜토리얼·인벤토리·결과 화면의 스킬 이름/설명을 돌진 찌르기로 변경했습니다.

## 에셋

내장 imagegen의 투명 배경 편집으로 제작했습니다. 기존 대기 캐릭터를 정체성·신체 비율 참조로 사용하고, 초기 생성 후 검 길이를 한 번 보정했습니다.

양손이 손잡이 뒤에 붙고, 손·손목·팔꿈치가 검을 미는 방향으로 이어지도록 구성했습니다. 검집에서 꺼내는 동작이나 횡베기는 사용하지 않습니다.

6포즈: 집중 준비 / 깊은 집중 / 발진 / 돌진 찌르기 / 찌른 뒤 제동 / 준비 자세 복귀.
완료 후에는 기존 평상시 캐릭터로 돌아갑니다. 평상시와 나란히 렌더링해 머리·갑옷 비율과 지면 접촉을 확인했습니다. 원본 생성 결과는 Java로 셀 위치와 발 기준만 정렬했습니다.

## 검증

Java/Gradle 컴파일과 실제 libGDX/OpenGL 창에서 자동 입력 검증을 통과했습니다.

- 2초/4단계, 충전 중 동작 차단, 2초 뒤 자동 돌진 및 회복
- 30/60/120fps에서 돌진 거리 210 유지
- 좌우 방향, 양쪽 맵 경계, 지면과 발판, 발판에서 돌진
- 전방 적 각각 한 번 20 피해, 뒤쪽/높이/범위 밖 대상 제외, 보스 30→10 HP
- 조기 해제, 피격/일시정지/공중 시작 처리, 키 재지정, 화면 버튼 유지/드래그
- 실제 메인 게임 루프에서 이동과 완료까지 확인
- 6단계 튜토리얼, 본편 진입, 상점, 보상/체크포인트, 결과/기록 및 보스 전투 회귀 검사
- 평상시/준비/찌르기/평상시 복귀 화면과 실제 게임 GIF의 주요 프레임 확인

자동 입력과 테스트 상태 구성을 조합했으며, 사람이 전체 게임을 수동 플레이한 검사는 아닙니다. 테스트는 메모리 설정/기록을 사용했습니다.
