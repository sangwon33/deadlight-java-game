# 2026-11-24 전투·튜토리얼·HUD 개편

이 문서가 이전 HUD·포션·점프·훈련 규칙보다 우선합니다. 월드 충돌과 지역 연결은 유지합니다.

## 전투와 아이템

- 치명타 기본 확률 20%, 피해 배율 200%. 일반 공격은 각 타마다, 찌르기는 시전마다 한 번 추첨하며 같은 동작에 맞는 적들은 같은 결과를 공유합니다. 치명타 피해 숫자는 빨간색입니다. 방어·빈틈 피해 보정과 무적 판정은 유지합니다.
- 공격력 포션: 10초 동안 강화가 반영된 공격력과 찌르기 피해 +100%.
- 신속 포션: 기본 3번 키, 10초 동안 이동속도 +50%(340 → 510). 키 설정에서 변경할 수 있습니다. 공격 중 이동 제한·대시 속도는 기존 규칙을 유지합니다.
- 같은 포션 재사용은 중첩하지 않고 10초로 갱신합니다. 메뉴·지도에서 효과 시간은 멈춥니다. 지역 이동 시 남은 시간과 수량을 유지하고, 재도전 시 지역 진입 체크포인트 상태로 복원합니다.
- 신속 포션은 상점 35골드, 기존 공격 포션 보급품에서 공격·신속 각각 1개를 얻습니다. 가방·HUD·사용 키·설명·상점 재고를 함께 연결했습니다.
- 점프 시작 속도 990 → 930(약 6% 감소). 별도 6프레임 공중 베기 에셋을 사용합니다.
- 드롭 코인의 지름을 약 1.7배 키웠습니다. 1.5초 대기 후 날아와 약 1.75초에 한 번 지급되는 규칙은 유지합니다.

## 튜토리얼

- 허수아비 HP 100,000, 넉백 없음. 직전 타격·3초 평균 DPS·누적 피해를 유지합니다.
- 3번째 과제는 적을 죽이지 않아도 지상 3타 동작을 끝내면 성공합니다. 허공에서 수행해도 인정합니다. 피격·대시·점프로 3타를 끝내기 전에 취소하면 인정하지 않습니다.
- 성공 후 초록색 `완료!`와 진행 선을 0.75초 표시하고 다음 과제로 이동합니다.
- 삼각형 이전·다음 버튼으로 완료한 과제 설명을 다시 볼 수 있습니다. 미완료 과제는 다음으로 건너갈 수 없으며 별도 건너뛰기 버튼을 제공합니다.
- 설명창을 상단 260×84 영역으로 줄였고 체력바·미니맵·아이템·스탯 영역과 분리했습니다. 허수아비 피해판은 가까이 있을 때만 표시하고 카메라 아래로 잘릴 때 숨깁니다.

## 표시와 탐색

- 체력바: 얇은 금속 테두리·하트 문장·내부 수치·피해 잔상. 보스는 은색 장식과 짙은 붉은 체력 띠, 잔상·수치를 사용합니다.
- 왼쪽 위: 체력바 → 골드 → 회복 → 공격력 → 신속 포션. 수량과 현재 사용 키, 버프 잔여 표시를 구분합니다.
- 선택형 상시 스탯: 아이템 아래 공격력·이동속도·공격속도·치명타 확률·피해 배율. Tab 전체 스탯에서도 체력을 제거했습니다.
- 오른쪽 위: 일시정지 아래 미니맵. 작은 격자, 밝은 지형선, 위치 표식과 이로운 요소의 초록 표식을 사용하며 실제 방문한 곳만 표시합니다.
- 가시·분출구·무너지는 발판은 빨간 윤곽, 보급품·회복 우물은 초록 윤곽. 바람·승강기는 초록 가장자리로 표시합니다.
- 공중 발판에는 가까운 아래 구조물에 닿는 기둥·받침 또는 위 구조물에 연결되는 사슬을 표시합니다. 장식은 충돌을 추가하지 않습니다.
- 무너지는 발판은 고정 비율 돌 블록을 반복하고 끝 부분을 잘라 그려 가로 늘어짐을 제거했습니다. 일반 발판 끝 타일도 잘라 그립니다.

## 상점

↑↓ 또는 W/S로 선택, Enter/Space로 구매, Esc로 닫기. 마우스 이동과 키보드 선택은 하나의 선택 항목을 공유하며, 고정된 마우스 포인터가 키보드 선택 표시를 가로채지 않습니다. 기존 마우스 구매도 유지합니다.

## 검증

작업 폴더의 native harness로 실제 libGDX 데스크톱 게임을 실행해 확인합니다. 테스트 입력·설정은 메모리에서 분리하며 사용자 설정 파일을 바꾸지 않습니다.

- 치명타 1,000회 추첨 분포, 강제 치명타 일반 공격·찌르기의 피해와 표시 전달.
- 30/60/120fps에서 3타 완료·대기·이전/다음·허수아비 생존·피해 누적·재화 중복 방지.
- 강화 중 공격 포션 2배·갱신·종료, 신속 실제 이동 거리·종료, 리바인딩, 키보드 구매·재도전 체크포인트.
- 1280×720, 960×540, 120% 글씨에서 HUD·튜토리얼·지도·포션·공중 동작·3지역 기믹·모든 보스 체력바와 OpenGL 오류 검사.
- 실제 입력으로 튜토리얼 7과제, 낮춘 점프로 전망 발판 도달, S 길게 살펴보기·짧게 내려가기·완료 대기·본편 진입.

규칙 변경 기록은 rules8을 사용하며 이전 기록은 보존합니다. 작업 전 전체 백업과 중간 저장본은 프로젝트 밖 `work/overhaul-1124`에 두었습니다. 커밋은 사용자 확인 후 별도로 진행합니다.
