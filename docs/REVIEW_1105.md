## 요청한 변경

### 캐릭터를 자르지 않는 범위까지 시야 확대

- 살펴보기 지연은 0.65초입니다.
- 카메라 추가 이동량을 위 44 → 72, 아래 88 → 148로 확대했습니다.
- 키를 놓으면 원래 추적 위치로 부드럽게 돌아옵니다.
- 몸 충돌 상자만으로 판단하지 않고, 현재 프레임의 실제 알파 외곽을 계산합니다. 기울어진 후드, 검, 엎드린 다리까지 포함해 화면 테두리에서 8 논리 픽셀의 여유를 확보합니다.
- 맵 가장자리에서는 필요한 만큼 소폭 화면을 더 보여주므로, 왼쪽/오른쪽 끝에서 엎드려도 그림이 잘리지 않습니다.
- 기존 위 보기/엎드려 보기 전용 이미지를 사용합니다. 이미지를 세로로 눌러 표현하는 렌더링 메서드는 제거했습니다.
- 카메라로 살펴보기만 한 곳은 탐색 지도에 기록하지 않습니다.

### S 웅크리기 제거와 이동 경로 정리

- 게임플레이의 기존 S 행동, 키 설정 항목, 화면 조작 버튼을 제거했습니다.
- 기본 조작은 W/↑ 위 보기, ↓ 아래 보기입니다. 아래 보기는 전용 엎드린 자세이며 S 웅크리기와 별개입니다.
- 얇은 발판/승강기 아래로 이동하려면 아래 보기 키를 누른 채 점프 키를 누릅니다. 기본 조합은 **↓ + Space**입니다.
- ↓만 유지하면 발판/승강기 위에서 살펴봅니다. 점프 키를 계속 누른다고 여러 층을 연속으로 통과하지 않습니다.
- 단단한 바닥에서 내려가기 조합을 눌렀을 때 반대로 점프하지 않도록 입력을 처리했습니다.
- 웅크려야 통과했던 지하 통로의 높이를 늘려 서서 이동할 수 있도록 했습니다.
- 튜토리얼 6번째 과제는 0.65초 아래 살펴보기로 바꿨고, 발판 내려가기 조합도 안내합니다.
- 기존 유효한 다른 행동의 사용자 키 설정을 보존합니다. 예전 DOWN 저장 항목은 읽지 않습니다. 사용자가 다른 행동에 S를 직접 지정하는 것은 가능합니다.

## 검수 중 추가로 고친 문제

| 발견한 문제 | 수정 |
|---|---|
| 선택형 화면 조작 버튼의 아래쪽이 가방/일시정지 클릭 영역과 겹침 | 가방/일시정지 영역을 버튼 위로 옮겨 분리 |
| 위를 볼 때 하단 보스 체력바가 플레이어를 가릴 수 있음 | 보스 체력바를 상단 중앙으로 이동하고 중복 목표/지역 안내를 정리 |
| 맵을 줄인 뒤 승강기가 이전 폭을 유지해 통로 옆 단단한 바닥과 겹침 | 첫 승강기를 수직 통로 안으로 옮기고 두 승강기의 폭을 새 맵 비율에 맞춤 |
| 지도에서 승강기 폭/중심을 150/75로 고정해 실제 발판과 달라짐 | 실제 승강기 너비/중심으로 지도에 표시 |
| Tab을 유지해 지도를 보는 중 Esc가 무시됨 | 지도 입력 처리 전 Esc를 확인하고 지도를 닫은 뒤 일시정지 |
| S 제거 후 기존 지하 통로와 튜토리얼이 더 이상 맞지 않음 | 서서 통과 가능한 통로와 살펴보기 과제로 함께 변경 |
| 맵 양끝에서 몸 충돌 상자 밖의 검/엎드린 몸이 잘릴 수 있음 | 이미지 알파 외곽을 사용한 화면 여유 제한 추가 |
