# 중력 응축과 폭발형 차징 연출

적용 위치: `C:\Users\USER\Desktop\Java\Deadlight`

요청한 슈퍼 노바의 중력 응축과 묵직한 한 방 느낌을 이 게임의 검 캐릭터와 4단계 충전 조작에 맞춰 구성했습니다.

- 충전: 무기 앞에 어두운 고밀도 구체가 생기고, 주변 빛과 지면 파편이 안으로 빨려 들어갑니다. 단계가 높아질수록 구체와 빛의 가장자리가 짙어지고 바깥 궤도는 수축합니다.
- 최대 충전: 금빛 테두리와 짧은 전기 궤적, 내부의 밝은 핵으로 응축된 상태를 표시합니다.
- 놓기: 기존 발동 준비 시간 동안 구체를 전방으로 압축한 뒤, 실제 공격 판정 시점에 국소 섬광과 폭발이 발생합니다. 이어 압력 고리, 지면 충격파, 짧은 빛의 균열, 튀어 오르는 파편이 남습니다.
- 무게감: 발동 때 짧은 수평 카메라 진동과 화면 가장자리의 약한 빛을 더했습니다. UI 카메라는 고정이며 월드 경계를 지킵니다.
- 소리: 직접 합성한 충전 저음과 발동 타격음을 추가했습니다. 효과음 음량 설정을 따르며, 충전음은 피격 취소·일시정지·메뉴·지역 이동 때 정리됩니다. 발동음은 실제 타격 시작 시 스킬당 한 번 재생합니다.

기존 약 1초/4단계 충전, 단계 색상, 놓기 조작, 피해·범위·재사용 대기시간과 적당 한 번 적중 판정은 유지합니다.

변경: `ShockSlashView.java`, `Main.java`, `CombatFeedback.java`, 새 `SkillAudio.java`, 새 `assets/audio/gravity_charge.wav`, `assets/audio/gravity_blast.wav`.

검증: Java/Gradle 컴파일, 밝은/어두운 맵의 연속 OpenGL 렌더링, 좌우 방향·잔상 수명·일시정지·피격·지역 초기화·GL 상태 복구를 통과했습니다. 실제 게임 업데이트로 1회 폭발 및 기본 풀 차징 피해 6, 충전음의 음소거/일시정지/피격/지역 정리, 월드 카메라 반응과 HUD 고정, 진동 종료 후 위치 복구를 검사했습니다. 기존 차징 입력/키 변경/화면 버튼/상점과 전체 튜토리얼·보상·재도전·보스·기록 자동 검사도 통과했습니다. WAV는 44.1kHz 모노 PCM이며 최대 진폭을 제한했습니다. 오디오 장치를 비활성화한 자동 검사로 재생 호출과 수명주기를 확인했습니다.

미리보기 `Deadlight_gravity_nova_1102.gif`는 실제 게임 캡처이며 무음입니다. 통합 ZIP도 갱신했습니다. 실행 중인 게임을 닫고 Eclipse에서 F5 후 다시 실행하세요.
