# Deadlight 한글 UI 배치 수정 (2026-11-02)

적용 위치: `C:\Users\USER\Desktop\Java\Deadlight`

- 설정 제목과 음량 안내 사이에 여백 확보. 여섯 설정 항목과 하단 저장 안내를 분리하고, 배경 그림에 글자가 묻히지 않도록 설정 영역을 정리했습니다.
- 키 설정에서 행동 이름과 지정 키를 별도 열에 배치했습니다. 긴 키 이름과 변경 안내는 정해진 영역에 맞추고, 마지막 Q 항목도 다른 항목과 같은 버튼으로 표시합니다.
- 상점의 제목/설명, 상품명/효과, 인벤토리 제목/설명을 분리했습니다.
- 지역 선택의 하단 기록 안내가 패널 안에 표시되도록 패널을 확장했습니다.
- 결과 화면의 통계 값, 강화/행동 내역, 최고 기록 및 지역별 마지막 행과 안내 사이 간격을 확보했습니다.
- 진행 HUD의 제목/목표/진행 막대 간격을 확보했습니다. 가방·포션·스킬에 긴 키 이름을 지정해도 옆 영역으로 넘어가지 않도록 표시 폭을 제한했습니다. 화면 조작 버튼 아래 키 이름의 하단 잘림도 수정했습니다.
- 공통 버튼 글자 정렬에 한글의 실제 글리프 높이를 사용하고, 너비와 높이 모두 영역 안에 맞춥니다. 글자 표시 후 폰트 배율과 색은 원래대로 복구합니다.

수정 소스: `Main`, `UiTheme`, `ShopView`, `InventoryView`, `ResultView`, `JourneyView`, `GameHud`, `GameControls` (8개 Java 파일).

검증: 실제 OpenGL 실행으로 설정·키 설정·지역 선택·상점·인벤토리·보상·결과 화면을 1280×720 및 960×540에서 렌더링해 확인했습니다. 긴 키 이름과 큰 통계 숫자를 포함했고, 공통 라벨의 실제 정점 좌표가 버튼 밖으로 나가지 않는지 검사했습니다. 컴파일 및 기존 튜토리얼/보상/재도전/보스/키 저장 자동 실행 검사도 통과했습니다. 테스트에는 메모리 Preferences를 사용해 사용자 설정과 기록을 변경하지 않았습니다.

실행 중인 게임을 닫고 Eclipse에서 F5로 새로고침한 뒤 다시 실행하세요. 통합 소스 ZIP에도 이번 변경을 반영했습니다.
