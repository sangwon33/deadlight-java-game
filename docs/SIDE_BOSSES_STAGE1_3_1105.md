# 1·3스테이지 선택형 중간 보스 — 2026-11-05

## 진입과 진행
- 1지역: 기존 x≈1450 / 높이 460의 상층 길에서 높이 540→620→700→780→860 발판을 올라갑니다. 마지막 발판 오른쪽 끝에서 왼쪽으로 점프하여 높이 940의 뿌리 예배당에 들어갑니다.
- 3지역: x≈3550 / 높이 980의 높은 보급로에서 높이 1060→1140→1220으로 올라갑니다. 높이 1220 발코니는 x4100~4780으로 이어집니다. 오른쪽 바깥 끝으로 걸어가 왼쪽으로 점프하면 높이 1300의 봉합자의 정원에 들어갑니다. 도약 공간을 위해 지역 상단을 기존 1420에서 1680으로 높였습니다.
- Tab 지도에 `선택 · 순례자` / `선택 · 봉합자`를 표시합니다.
- 입구 안쪽에서 땅에 선 뒤 상호작용하면 시작합니다. 기본 E이며 키 재설정을 따릅니다. 시작 전에는 공격하거나 피해를 받지 않습니다. 시작 시 문이 닫히고 보스 처치 즉시 열립니다.
- 일반 적은 기존 13/16/17마리, 필수 수문장은 지역별 1마리입니다. 선택 보스는 별도로 관리하며 처치하지 않고 다음 지역으로 진행할 수 있습니다. 2지역 등불지기는 기존 구현을 사용합니다.

## 1지역 — 뿌리에 잠든 순례자
- HP 108 / 기본 피해 18 / 체력 절반 이하 피해 22.
- 어깨 돌진: 준비 뒤 고정된 방향으로 짧게 돌진합니다. 점프·대시로 회피할 수 있습니다.
- 뿌리 가시: 준비 시 고정한 플레이어 위치 주변에 봉오리가 나타난 뒤 순차적으로 가시가 솟습니다. 가시당 1회 피해를 시도하고 유효 시간 후 사라집니다. 기본 3개, 격화 시 5개입니다.
- 뿌리 팔 휘두르기: 전방의 낮고 넓은 공격 후 회복합니다.
- 격화 시 속도 상승, 연속 2회 돌진. 공격 후 회복 동작에서 반격 1.5배를 적용합니다.
- 자동 보상 1회: 골드 60, 일반 공격력 강화 1회(+1), 회복 포션 1개.

## 3지역 — 재를 꿰매는 자
- HP 168 / 기본 피해 22 / 체력 절반 이하 피해 26.
- 바늘 찌르기: 준비 후 짧게 전진하며 찌릅니다.
- 도약/급강하: 준비 시 목표 위치를 고정하고 높이 145만큼 도약한 뒤 그 위치로 급강하합니다. 공중에서 플레이어를 따라 목표를 바꾸지 않습니다. 착지 후 반격할 빈틈이 있습니다.
- 낙하 바늘: 고정된 목표 위치와 양옆에 3개의 물리 바늘을 순서대로 떨어뜨립니다. 바늘은 유도하지 않으며 충돌·바닥 착지 시 제거합니다. 날아가는 바늘은 별도로 소환한 장비이므로 손의 무기와 구분됩니다.
- 격화 시 속도 상승과 연속 찌르기. 회복 중 반격 1.5배.
- 자동 보상 1회: 골드 100, 일반 공격력 강화 1회(+1), 공격 포션 1개.

## 상태와 렌더링
- `SideBossArena`: 지역별 공간·통로·이름·기본 수치. `StageLayout`에서 물리 지형을 생성합니다.
- `SideBoss`: 입력/그래픽과 분리된 상태 머신. 1/120초 이하로 나눈 업데이트, 이동 범위 제한, 돌진 스윕, 급강하 몸체 스윕, 낙하 바늘 선분 스윕, 가시별 피해 1회와 정리.
- `SideBossEncounter`: 도전 조건, 전투 문, 구역 장식·안내·체력바와 텍스처 수명.
- `SideBossSprites`: JSON에 기록한 명시적 프레임 영역·발 기준·이펙트 중심. 순례자 공통 배율 .265, 봉합자 .36. 투명 여백을 포함한 원본 셀 전체를 같은 비율로 그립니다. PNG의 픽셀/알파는 편집하지 않았습니다.
- `Main`: 플레이어 일반 공격/Q의 행동당 피해 1회, 보스 업데이트를 기존 피격 통계와 연결, 처치 보상, 수명 정리, HUD.
- 부딪히는 것만으로는 피해를 주지 않습니다. 공격 중에만 피해를 시도하며 플레이어의 기존 대시/피격 무적을 따릅니다.
- 보상은 기존 런 상태인 골드·공격 강화·포션을 사용합니다. 다음 지역으로 이어지며, 입장 체크포인트를 보상 수령으로 수정하지 않습니다. 해당 지역 실패 후 재도전 시 시도 중 보상은 되돌아가고 보스도 대기 상태로 재생성됩니다. 별도 영구 저장 유물은 추가하지 않았습니다.

## 검증과 한계
- 30/60/120fps에서 대기 면역·시작 조건·모든 패턴 순환·공간 제한·격화·반격 배율·피격 간격 확인.
- 돌진/찌르기 양방향 스윕과 점프 회피, 가시 1회 피해/수명/점프 회피, 급강하 고정 목표/착지, 낙하 바늘 스윕/횡이동 회피/제거 확인.
- 실제 `Player.update`로 두 새 경로 전체 및 입구 이동을 30/60/120fps에서 확인. 전투 문을 넘지 못하고 처치 후 통과할 수 있습니다. 발견한 3지역 60fps 착지 실패는 발코니 시작점을 x4140에서 x4100으로 당겨 수정했습니다.
- 실제 `Main` 일반 공격/Q 중복 방지, 보상 1회, 포션 종류와 공격력 적용, 입장 체크포인트 불변, 재도전 시 새 대기 상태 확인.
- 실제 `Main.updateGame`의 피해 통계·플레이어 무적 연결 확인. 나방·등불 사수·2지역 등불지기의 기존 검사도 통과했습니다.
- 모든 포즈의 공통 배율·양방향 발 기준과 색상 복원, 이펙트 회전 중심을 검사하고 프로덕션 그리기 명령을 Java2D 미리보기로 확인했습니다. 미리보기는 실제 게임 스크린샷이 아닙니다.
- Gradle 실행 JAR, Eclipse 출력 컴파일 및 실행 중인 Eclipse 워크스페이스 새로고침/증분 빌드: 프로젝트 3개 오류 마커 0, Java 편집기 클래스 로드 확인. `build/eclipse-side-bosses-check.txt`에 결과가 있습니다.
- 실제 게임 창의 GPU 렌더링과 수동 전투 체감·최종 난이도는 아직 확인하지 못했습니다. 현재 실행 중인 게임은 종료 후 재실행해야 새 코드가 적용됩니다.
