# 전투 피드백·튜토리얼·탐색 확장 — 2026-11-05

## 반영한 기능

### 1. 피해 잔상이 천천히 줄어드는 체력바
- 실제 체력 수치와 앞쪽 체력바는 피격 즉시 줄어듭니다.
- 잃은 구간은 붉은 잔상으로 0.5초 남고, 이후 초당 전체 체력바의 32% 속도로 줄어듭니다. 예를 들어 100에서 20 피해를 받으면 약 1.125초에 잔상까지 정리됩니다.
- 연속 피격 시 잔상을 유지하고 대기 시간을 다시 줍니다. 회복 시에는 오래된 피해 잔상을 정리합니다.
- 플레이어뿐 아니라 적/수문장/보스 체력바에도 같은 잔상 처리를 연결했습니다. 체력 회복 기능과는 별개의 표시입니다.

### 2. 작은 허수아비 훈련장
- 튜토리얼 폭을 1400에서 **1000**으로 줄였습니다. 기본 화면 폭 640 기준 약 1.56화면입니다.
- 훈련 대상은 고정된 허수아비입니다. 보통/피격/파괴 3프레임을 사용합니다.
- 기본 공격, 강한 공격, 파괴 시 모두 넉백 속도를 0으로 유지합니다. 이동/공격/골드 지급은 하지 않습니다.
- 튜토리얼 안내도 허수아비에 맞췄습니다. 기존 7개 조작 과제와 S 짧게/길게 조작을 유지합니다.

### 3. 자연스러운 보급품과 더 촘촘한 구조
- 월드에 놓이던 사각 UI 물약 아이콘을 없애고 바닥에 놓인 보급 가방/상자로 바꿨습니다.
- 가까이 있을 때만 작은 표식을 표시합니다. 접촉 수집과 보급 내용은 유지합니다.
- 각 일반 지역의 고정 발판을 28개에서 **40개**로 늘렸습니다. 추가 발코니 12개가 지상/상층 사이를 연결합니다.
- 배경 폐허의 간격을 245에서 155로 줄이고, 아치/석상/묘석/등불을 더 촘촘하게 배치했습니다.
- 발판 아래 돌기둥과 사슬 지지물을 추가했습니다. 배경 구조물은 색과 대비를 낮춰 충돌 지형/캐릭터와 구분합니다.

### 4. 점프 시작 속도 1.5배
- 점프 시작 속도 660 → **990**. 중력 -2050과 짧게/길게 누르는 점프는 유지합니다.
- 시작 속도를 1.5배로 올렸으므로 끝까지 누른 점프의 이론상 높이는 약 2.25배입니다. 30/60/120fps 실제 검사에서 지면 위 약 223~235 높이에 도달합니다.
- 상층에서 점프가 불필요하게 잘리지 않도록 일반 지역 위 경계에 100의 여유를 추가했습니다.

### 5. Tab 지도 개선
- 지역 제목, 은청색 테두리/모서리 장식, 격자, 나침반, 탐색 구역 윤곽을 추가했습니다.
- 현재 위치/방향, 미수집 보급품, 발견한 우물/승강기/바람, 분출 함정/닫힌 문을 구분해 표시합니다.
- 미탐색 지형/기믹/보급품은 계속 숨깁니다. 카메라로 살펴보기만 한 곳도 기록하지 않습니다.
- 무너진 발판은 원래 선을 숨기며 현재 상태를 반영합니다.
- Tab 유지 중 일시정지, Esc로 닫고 일시정지, 모험 내 재도전 탐색 유지/새 모험 초기화 규칙을 유지합니다.

### 6. 붉은 강화 수문장
- 세 일반 지역의 수문장 크기/몸 충돌/공격 범위를 기존의 1.5배로 키웠습니다.
- 기존 수문장 체력 36 → **54**, 공격력 20 → **30**.
- 붉은 몸 색, 붉은 외곽 빛, 붉은 이름 표식으로 일반 적과 구분합니다.
- 최종 보스는 이 수문장 배율의 대상이 아닙니다.

### 7. 지역별 기믹 추가
각 일반 지역에 아래를 추가했습니다.
- **무너지는 발판 2개:** 올라서면 균열/붉은 안내를 표시하고 0.85초 후 무너집니다. 4초 뒤 복구됩니다. 지하 샛길과 연결됩니다.
- **분출 함정 2개:** 붉은 예고 뒤 약 0.65초간 분출합니다. 피해 20, 무적 시간과 대시 회피를 적용합니다. 뒤 지역일수록 주기가 짧습니다.
- **회복 우물 1개:** 근처에서 현재 상호작용 키(E 기본)를 누르면 체력 +30. 한 번만 쓰며 만피일 때는 소모하지 않습니다.
기존 바람 4개, 승강기 2개, 석문/레버 1개, 가시 구간 3개와 함께 사용합니다. 재도전 시 기믹은 지역 진입 상태로 초기화됩니다.
- 무너진 발판 위에 적이 공중에 남지 않도록 적의 지형 중력/착지를 연결했고, 이동 승강기 위에서도 높이를 따라가도록 했습니다.

### 8. 스킬 사용 가능 알림
- 스킬 재사용이 끝나면 슬롯이 빛나고 짧은 광선과 ‘스킬 준비’ 안내를 표시합니다.
- 공중/다른 동작 때문에 아직 사용할 수 없다면 실제 사용 가능한 상태가 됐을 때 알림을 줍니다.
- 준비 상태의 은은한 테두리와 선택형 화면 조작 버튼의 빛도 적용했습니다.
- 기존 수정/검토용 스킬 재사용 1초는 유지합니다.
