# 현재 작업 버전

Eclipse에 등록되어 있는 실제 프로젝트와 최신 수정본을 이 폴더로 통합했습니다.

`C:\java game\Deadlight\Deadlight`

## 실행

이 폴더의 `PLAY.cmd`를 실행하세요. Eclipse도 이 폴더의 core/lwjgl3 프로젝트를 사용합니다.
외부에서 파일이 갱신되었으므로 Eclipse에서는 프로젝트를 새로고침(F5)한 뒤 실행하세요.
하위 `Deadlight` 폴더는 사용하지 않는 이전 작업 사본입니다.

## 2026-10-31 지역 보상·결과 화면 묶음

- 1~3지역 출구에서 다음 지역으로 이동하기 전에 보상 카드 3개 중 하나를 고릅니다. 기존 출구 도달 조건은 유지합니다.
- REST: 체력을 전부 회복합니다. 이미 최대 체력이면 회복 포션 1개를 받습니다. GOLD: 골드 30을 받아 다음 상점에서 쓸 수 있습니다. FORTIFY: 이번 플레이의 현재·최대 체력이 1 증가합니다.
- 마우스로 카드를 누르거나 1/2/3, A/D, 좌우 방향키로 선택한 뒤 `TAKE ... & CONTINUE` 또는 Enter로 확정합니다. 카드를 누르기만 해서는 지급되지 않습니다. Escape는 일시정지하며 선택을 유지합니다.
- 보상 선택 중에는 전투·플레이 시간·쿨타임·버프 시간이 멈춥니다. 보상은 지역당 한 번 지급하고, 보상 적용 후 다음 지역의 진입 상태를 저장합니다. 사망 후 재도전하면 기존 지역에서 받은 보상은 유지하며 실패한 지역에서의 추가 구매·소비·골드는 진입 당시로 복원합니다.
- 결과 화면은 SUMMARY / REGIONS & REWARDS 탭으로 나뉩니다. 마우스, Tab, 좌우 방향키로 전환합니다. 상점 공격/체력 강화와 보상 체력 증가, 일반 공격·Q 시전·대시 횟수를 표시합니다.
- 지역별로 클리어 여부·실제 플레이 시간·받은 피해·재도전·포션 사용·행동 횟수·선택한 보상을 보여 줍니다. 시간·피해·포션·행동은 실패한 시도까지 합산합니다. 중간 지역 연습은 실제로 방문한 지역만 기록합니다. Q 시전 횟수에는 도중에 취소된 사용도 포함합니다.
- 결과 기록은 완료 시점에 복사해 재도전·새 플레이로 바뀌지 않습니다. 이번 보상은 새 플레이를 시작하면 초기화됩니다. 원본 픽셀 그림과 제거한 적/보스 공격 예고 표시 상태는 유지합니다.

## 2026-10-31 전투 가독성 묶음

- 사용자 요청으로 일반 적과 보스의 공격 예고 범위선·`!`·방향·높이·남은 시간 표시를 제거했습니다. 보스 HUD는 이름과 체력만 표시하도록 줄였습니다. 공격 준비 동작·속도·범위·피해량은 유지합니다.
- 실제로 피해를 받았을 때 `HIT -피해량`과 짧은 화면 가장자리 표시를 보여 줍니다. 피격 글자에는 어두운 배경을 붙였습니다. 처음 피격 효과가 보이는 동안은 무적 깜빡임으로 캐릭터가 흐려지지 않습니다.
- Q 도중 피격되면 `Q INTERRUPTED`와 남은 쿨타임을 표시합니다. 무적 중 막힌 공격에는 피격/취소 효과가 중복으로 생기지 않으며, 일시정지·상점·인벤토리에서는 안내 시간도 멈춥니다.
- 피해 숫자는 적 머리 위에 배치하고 가까운 여러 적을 맞히면 세로로 분산합니다. 보스 피해 숫자는 보스 HUD 아래에서 보이도록 제한합니다.
- 튜토리얼은 이동 → 점프 → 공격 → 대시 → Q의 5단계입니다. Q의 준비·타격·회복 동작을 끝내야 완료되며, 취소되면 재사용까지 남은 시간을 알려줍니다. 기사 방패 해제와 8초 쿨타임도 안내합니다. SKIP, 재도전의 진행 복원, 중간 지역 연습 시작을 함께 반영했습니다.
- 캐릭터 PNG와 맵은 수정하지 않았습니다.

## 2026-10-31 UI·밸런스·Q 스킬 묶음

- 상단 HUD를 체력·포션, 지역 진행·시간, 골드·메뉴로 정렬했습니다. 포션 지속 시간은 아이콘 옆에 표시하며, 보스 체력바와 튜토리얼 패널도 작게 정리했습니다.
- Q 또는 화면의 금색 버튼: 충격 베기. 기본 피해 3(현재 공격력 +2), 준비 0.30초 → 타격 0.16초 → 회복 0.28초, 재사용 8초입니다. 앞쪽의 여러 적을 각각 한 번 타격하며, 시전 중 방향을 고정합니다. 무적은 없고 피해를 받으면 취소됩니다. 취소되어도 재사용 시간은 남습니다.
- 기사는 경직된 뒤 1초 동안 일반 공격에 다시 경직되지 않습니다. 금색 방패 표시로 알리며 Q 충격 베기로 공격과 버티기 상태를 끊을 수 있습니다. 일반 공격의 피해량은 줄지 않습니다.
- 체력 강화는 40G에 최대·현재 체력 +3, 회복 포션은 최대 체력의 절반(올림), 공격 포션은 공격력 +2·8초입니다. 공격 포션을 다시 사용하면 중첩 없이 8초로 갱신합니다.
- 상점·인벤토리 설명과 다음 지역/재도전 시 능력치 복원에도 같은 수치를 적용했습니다. 일시정지·상점·인벤토리에서는 스킬 진행과 쿨타임이 멈춥니다.
- 캐릭터 PNG와 픽셀 질감, 맵 구성은 유지했습니다. 스킬 이펙트는 코드로 그립니다.

## 2026-10-31 실행·모션·전투 점검

- 잘못 이름 붙은 검은 사망 이미지를 `enemy/dark_slime_death.png`로 분리해 검은 슬라임에 연결했습니다. 초록 슬라임은 초록 대기 원본을 재사용해 같은 비율로 작아지며 사라지므로 검은 그림으로 바뀌지 않습니다.

- Eclipse가 상위 프로젝트의 예전 코드/이미지를 읽던 문제를 확인해 최신 코드·이미지·Eclipse 실행 산출물을 같은 폴더로 통합했습니다.
- 기사와 슬라임은 가로·세로에 같은 배율을 적용해 원본 비율을 유지합니다. 슬라임 이동 칸에 끼어 있던 옆 프레임 조각을 화면에서 제외하고 실제 몸의 바닥을 기준으로 정렬했습니다.
- 보스 대기 모션의 가로 늘어짐을 제거하고, 대기/공격 사이의 발 기준 차이로 발생하던 세로 위치 튐을 수정했습니다.
- 일반 적은 휘두르는 앞쪽과 실제 공격 높이에만 피해를 주며, 뒤나 공격 높이 밖으로 피한 플레이어를 맞히지 않습니다.
- 플레이어 공격은 준비/복귀 모션에서 피해를 주지 않고 실제 타격 프레임에서만 피해를 줍니다.
- 넉백으로 적이 스테이지 밖으로 빠지는 현상과 상점/인벤토리 전후에 이전 행동 입력이 남는 경우를 방지했습니다.
- 캐릭터 원본 PNG의 픽셀 그림은 새로 그리지 않았습니다.

## 조작

- A / D: 이동. 화면 왼쪽의 두 버튼도 사용 가능합니다.
- Space: 점프, J: 공격, Shift: 대시, Q: 충격 베기. 오른쪽 화면 버튼과 함께 사용할 수 있습니다.
- 대시는 사용 순간부터 5초 쿨타임이 적용됩니다.
- Escape: 일시정지 / 재개. 창을 벗어나도 자동으로 일시정지합니다.
- 일시정지 화면의 재시작·메인 메뉴는 확인 후 진행합니다.
- I: 인벤토리, 1 / 2: 포션 사용, E: 상점.
- HUD의 일시정지·인벤토리 안내도 클릭할 수 있습니다.
- M: 배경 음악 음소거.
- 설정에서 음악·효과음 볼륨과 화면 버튼 표시 여부를 저장할 수 있습니다. 전체화면도 전환할 수 있습니다.

## 개발 모드

일반 실행에서는 N 스테이지 건너뛰기가 꺼져 있습니다. JVM 옵션 `-Ddeadlight.debug=true`를 지정한 개발 실행에서만 사용할 수 있습니다.

캐릭터 원본 픽셀 질감을 유지했습니다. 3스테이지의 대비·외곽선 처리는 렌더링 효과입니다.

## 2026-10-30 UI 점검 반영

- 화면 조작 버튼 전체를 지면 아래에 배치해 적과 공격 모션이 가려지지 않게 했습니다. 짧은 클릭이 점프·공격·대시 입력에서 누락되는 경우도 수정했습니다.
- 일반 슬라임의 대기·이동·공격·사망 모션은 원본 픽셀을 그대로 사용하면서 몸 크기와 바닥 기준을 맞췄습니다. 적 체력바는 각 적의 몸 높이를 따라갑니다.
- 인벤토리에 마우스 닫기, EMPTY/FULL HP 상태, 사용 결과 안내를 추가했습니다. 체력이 가득 차면 회복 포션은 소비하지 않습니다.
- 메인 메뉴·설정·스테이지 선택·인벤토리·HUD를 어두운 패널과 금색 테두리로 맞췄습니다.
- 설정의 음악·효과음은 -/+로 25%씩 조절합니다. 0~100%에서 멈추며, +로 음소거를 해제할 수 있습니다.
- 스테이지 선택에 지역명·배경 미리보기·난이도·적 정보와 기본 능력치로 시작한다는 안내를 추가했습니다.
- 보스 체력바에 이름·현재/최대 체력을 추가하고, 3스테이지의 밝은 외곽선을 약하게 조정했습니다.

## 추가 플레이 기능

- 1스테이지에 이동 → 점프 → 공격 → 대시 → Q 튜토리얼을 추가했습니다. 실제 동작 성공을 확인하며, 막힌 입력·벽에 붙어 이동하기·공중에서 점프 누르기·취소된 Q는 성공으로 처리하지 않습니다. SKIP으로 생략할 수 있습니다.
- 보스 공격 예고 UI는 제거했습니다. 공격이 끝날 때까지 준비 동작에서 정한 방향을 유지합니다.
- 사망 후 Enter 또는 RETRY STAGE로 현재 지역에 재도전할 수 있습니다. 지역 진입 당시 체력·강화·골드·포션·버프와 이전 지역 보상을 복원합니다. 실패한 구간에서 획득한 골드·강화는 중복으로 누적되지 않습니다. R / NEW RUN은 처음부터 시작합니다.
- 상점에 실제 구매 전후 공격력·현재/최대 체력·포션 효과를 표시합니다. 이미 공격 포션을 사용 중이면 추가 중첩 대신 8초 갱신으로 안내합니다.
- HUD에 지역명·처치 수·출구까지의 진행률·실제 플레이 시간을 표시합니다. 출구 표지와 상점의 위치를 구분했습니다. 보스 구간은 보스 체력 기준 진행률을 표시합니다.
- 결과 화면에서 플레이 시간·받은 피해·포션 사용·재도전 횟수를 확인할 수 있습니다. 시간·피해·포션 사용은 재도전 이전 시도까지 합산하며, 일시정지·상점·인벤토리·지역 전환 시간은 제외합니다.
- 최고 클리어 시간·최소 받은 피해·클리어 횟수를 로컬에 저장합니다. 1지역부터 시작한 전체 진행과 중간 지역부터 시작한 연습 기록은 따로 관리합니다. 메인 메뉴와 지역 선택에서 기록을 볼 수 있습니다.
