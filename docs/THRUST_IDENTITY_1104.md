기존 돌진 시트가 평상시와 다른 밝은 둥근 갑옷, 큰 붉은 망토, 검 모양으로 보이던 점을 수정했습니다. 대기 에셋 player_idle.png와 달리기 시트를 기준으로 집중·발진·찌르기·제동·회복 6자세를 다시 제작했습니다.

- 각진 어두운 후드와 검은 얼굴 공간
- 어두운 갑옷/가죽, 작은 금속 하이라이트와 사각 허리띠
- 검은 겉망토와 짙은 붉은 안감/찢어진 끝
- 원본처럼 가늘고 약간 휜 은색 검날, 어두운 손잡이와 은색 가드
- 평상시의 머리/몸 비율에 맞춘 표시 크기, 공통 발 기준과 좌우 반전
- 손은 같은 손잡이에 모으고 집중→앞으로 찌르기의 자세를 유지

내장 imagegen의 투명 배경 편집 모드로 제작했으며, 한 번의 검날 보정을 거쳤습니다. 생성 이미지의 불투명 연결 요소를 Java로 각 셀에 옮겨 발/몸 중심만 정렬했습니다. 이미지 편집은 imagegen으로 수행했습니다.

- 실제 게임 미리보기의 주요 프레임과 전후 비교 확인

자동 입력과 상태 구성을 사용했으며 사람이 전체 게임을 수동 플레이한 검증은 아닙니다. 테스트 설정/기록은 메모리에서만 사용했습니다. 직전 시트/메타데이터/로더는 work/identity-1104/before에 보존했습니다.
