# 상점 키 안내와 4단계 차징 스킬

적용 프로젝트: `C:\Users\USER\Desktop\Java\Deadlight`

상점 NPC 근처에서 기존 상점 아이콘 위에 `[현재 상호작용 키] 상점`을 표시합니다. 키 설정을 바꾸면 안내와 실제 상점 조작이 함께 바뀝니다.

충격 베기(기본 Q): 누르고 있는 동안 충전하고, 놓으면 현재 단계로 발동합니다. 최대 충전 후에도 누르고 있으면 충전을 유지합니다. 약 1초에 4단계에 도달합니다.

| 단계 | 충전 시간 | 색 | 기본 공격력 1일 때 피해 | 사거리 |
|---|---|---|---|---|
| 1 | 0~약 0.33초 | 흰색 | 2 | 75 |
| 2 | 약 0.33~0.67초 | 하늘색 | 3 | 90 |
| 3 | 약 0.67~1초 | 보라색 | 4 | 105 |
| 4 | 약 1초 이상 | 금색 | 6 | 120 |

- 캐릭터 옆 충전 효과, HUD의 단계 표시, 화면 스킬 버튼에 단계 색을 적용했습니다. 발동 효과도 해당 색을 사용합니다.
- 충전 중에는 느리게 이동하며 방향을 바꿀 수 있습니다. 놓은 뒤에는 공격 방향을 고정합니다.
- 발동 또는 피격 취소 시 8초 재사용 대기시간이 시작됩니다. 충전 중에는 피해가 발생하지 않고, 발동 시 적마다 한 번씩 적중합니다. 기존 방패 해제/강한 공격 판정을 유지합니다.
- 화면 버튼을 길게 누르는 조작도 지원합니다. 버튼을 누른 채 커서를 밖으로 옮겨도 충전을 유지하고, 마우스를 놓으면 발동합니다.
- 메뉴/일시정지/포커스 상실로 조작을 정리할 때는 충전을 취소해 복귀 시 저장된 공격이 발동하지 않게 했습니다.
- 튜토리얼의 스킬 과제를 최대 충전 후 놓기로 바꾸고, 인벤토리와 HUD 설명도 갱신했습니다.

검증: 실제 OpenGL 실행과 별도 누름/유지/해제 입력으로 4단계 진입 시점, 최대 충전 유지, 단계별 피해/사거리, 적당 1회 적중, 쿨타임, 피격/일시정지 취소, 키 재지정, 화면 버튼 유지/드래그/놓기, 튜토리얼의 최대 충전 조건, 변경된 상점 키 표시/상점 열기를 확인했습니다. 전체 튜토리얼부터 보상·재도전·상점·보스·기록·키 저장까지 기존 자동 실행 검사도 통과했습니다. 실제 사용자 설정과 기록은 수정하지 않았습니다.

통합 ZIP도 갱신했습니다. 실행 중인 게임을 닫고 Eclipse에서 F5를 누른 뒤 다시 실행하세요.
