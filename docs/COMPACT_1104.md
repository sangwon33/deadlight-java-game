# Deadlight — 자세·밀집 맵·간결한 HUD (2026-11-04)

## 살펴보기와 입력

- 위 보기: 기본 W 또는 ↑. 아래 살펴보기: 기본 ↓. 둘 다 0.65초 동안 유지하면 카메라가 부드럽게 이동합니다.
- S는 웅크리기/얇은 발판 한 칸 내려가기에만 사용합니다. ↓와 분리했으므로 아래를 살펴보다가 발판/승강기에서 떨어지지 않습니다.
- 설정 → 키 설정에서 위 보기/아래 살펴보기/내려가기를 각각 변경합니다. 14개 행동을 두 열에 배치했습니다. 기존 사용자 키를 우선하며 기본 방향키 보조 입력도 직접 지정한 행동에 우선하지 않습니다.
- 위를 볼 때는 고개와 후드를 들어 올린 전용 자세, 아래를 볼 때는 엎드려 아래를 내려다보는 전용 자세를 사용합니다. 엎드리기에는 두 호흡 프레임이 있습니다.
- 기존 서 있는 캐릭터와 같은 62.4 높이를 기준으로 공통 배율을 적용하고 각 프레임의 발/몸 접지선을 맞췄습니다. 엎드린 그림을 강제로 서 있는 높이에 늘리지 않습니다.
- 둘러보기는 지상에서 가만히 있을 때만 적용됩니다. 이동/점프/공격 등으로 즉시 전환할 수 있습니다. 아래 보기의 몸 높이는 기존 낮은 자세와 같은 32입니다.
- 기본 추적 높이를 발 위 100으로 조정하고, 카메라 추가 이동량을 위 44/아래 88로 줄였습니다(직전판은 양방향 144). 캐릭터가 화면 안에 남도록 카메라 위치에도 제한을 적용했습니다.
- 키 해제 시 부드럽게 복귀하고 반대 방향/메뉴/지도/일시정지/지역 전환에서는 대기 시간을 새로 시작합니다.
- 시야 확보만으로 지도 탐색 기록은 공개되지 않습니다.

## 더 촘촘한 지역

| 지역 | 이전 가로 | 새 가로 | 정상 높이 |
|---|---:|---:|---:|
| 신록의 폐허 | 4800 | 3000 | 690 |
| 성벽 | 5200 | 3200 | 732 |
| 잿빛 전장 | 5600 | 3400 | 774 |

- 가로 이동 공백을 약 38~39% 줄였습니다. 지상보다 높은 발판의 간격도 좁혔습니다. 맵 바닥은 -260, 위 경계는 900/960/1020입니다.
- 각 지역에 징검 발판 5개와 새 보급 지점을 추가해 고정 발판 28개, 이동 승강기 2개, 적 12명, 보급 지점 6개를 배치했습니다.
- 지하 샛길/낮은 통로/승강기/바람/레버와 석문/상층 탑/수문장과 출구 구조를 유지하면서 적과 보급품을 함께 재배치했습니다. 바람 세기도 새 높이에 맞췄습니다.
- 새 장식 아틀라스의 폐허 아치, 석상, 묘석과 항아리, 등불을 실제 바닥/발판 높이에 배치했습니다. 배경 장식은 색과 대비를 낮추고 충돌 지형/플레이어/적 뒤에 그려 구분합니다.
- 클리어 기록은 rules4로 분리합니다. 기존 규칙의 기록은 삭제하지 않습니다.

## UI에서 덜어낸 것과 남긴 것

- 화면 아래의 큰 마우스 조작 버튼을 기본 화면에서 껐습니다. 최초 개편 적용 시 한 번 끄며 이후에는 설정에서 다시 켠 선택을 유지합니다.
- 상시 타이머/일반 적 처치 수/출구 진행률/‘준비 완료’ 문장/상시 스킬 설명을 제거했습니다. 시간과 상세 통계는 결과 화면에 남아 있습니다.
- 일반 적의 ‘공격 준비’, ‘빈틈·반격’ 문구를 제거했습니다. 바닥의 공격 예고선과 빈틈 색상은 유지합니다. 수문장 표식과 보스 패턴 안내는 유지합니다.
- 일반 적의 체력바는 피해를 입었을 때 표시합니다. 수문장과 방어 중인 적은 식별을 위해 계속 표시합니다.
- 좌상단: 체력 수치/바, 현재 키가 함께 표시된 포션 수량. 우상단: 골드.
- 상단 중앙: 지역 이름과 필요한 목표 한 줄. 튜토리얼과 지역 안내는 짧은 맥락 안내로 표시합니다.
- 좌하단: Q/대시의 작은 재사용 표시, 시전 중에는 집중 단계만 짧게 표시합니다.
- 우하단: 가방/일시정지의 작은 클릭 영역. 보스 체력바는 아래 중앙에 배치합니다.
- 미니맵은 128×86에서 102×68로 줄이고 주변 720×320 구역을 확대해 보여줍니다. Tab 큰 지도와 ‘방문한 곳만 표시’ 원칙은 유지합니다.

## 검증

실제 LWJGL/OpenGL 게임 창을 띄우고 누름/유지/해제 입력을 분리해 주입했습니다. 검증에는 메모리 설정을 사용하여 사용자 키/세이브를 건드리지 않았습니다.

- COMPACT FEATURES: 30/60/120fps의 0.65초 지연, 줄어든 카메라 범위/캐릭터 화면 내 유지, 위 보기와 엎드린 자세, ↓ 유지 중 발판/승강기 유지, S로만 내려가기, 재설정된 키, 이동 시 둘러보기 해제, 메뉴/지도 대기 초기화, 카메라 탐색 비공개.
- COMPACT ROUTES: 세 지역 모두 실제 바람/점프 입력으로 상층 보급품과 정상 보급품까지 도달.
- JOURNEY: 7개 튜토리얼 과제, 세 지역의 수문장/출구, 지하 보급품, 재도전 시 기믹/보급품 복구, 상점/지역 보상/체력 강화 이월, 실제 일반 공격으로 보스 클리어, 지역 통계/새 규칙 기록.
- MAP: 미발견 바닥/기믹이 그려지지 않는 픽셀 비교, 실제 이동 공개, 분리된 탐색 지점, 지역별 구분, 재도전 유지/새 모험 초기화, 지도 중 정지, 튜토리얼 문장 크기.
- UI: 1280×720과 960×540의 16개 실제 화면, 로비 키보드/클릭, 음량/키 설정, 가방/포션/닫기, 일시정지/설정 복귀.
- PREVIEW: 실제 시야 이동/복귀/엎드린 자세 112프레임 GIF와 장식/적/HUD의 OpenGL 렌더링.
