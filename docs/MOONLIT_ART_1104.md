## 화면 연출과 연결 코드

- MoonAtlas.java: 투명 아틀라스 로드, 공통 텍스처 공유/해제, 프레임별 발끝 기준, 동일한 기준 프레임 배율 적용.
- Player/Enemy/FallenGod: 기존 상태와 타격 타이밍에 새 그림을 연결했습니다. 찌르기 자세만 별도 캐릭터처럼 커지지 않도록 공통 배율을 사용합니다.
- TerrainTile: 새 지형의 연속된 윗면을 실제 충돌 높이에 맞춥니다.
- Main: 새 배경/아이템/상점 연결, 은은한 배경 빛가루와 가장자리 음영, 이동에 따른 느린 배경 이동.
- 배경은 반복 타일 대신 한 장을 제한된 범위에서 이동시켜 이음새를 없앴습니다.
- UI/체력바/화면 버튼을 금색·초록 중심에서 은청색 중심으로 변경했습니다. 공격 경고와 위험 색은 구분을 위해 유지합니다.
- 타이틀의 한글 메뉴와 기존 가독성/폰트 기준선을 유지했습니다.

배경 빛가루는 환경 연출이며 플레이어 스킬 전용 이펙트는 추가하지 않았습니다.

## 유지한 플레이 규칙

크기 0.8, 체력 100/기본 피격 20, 가변 점프/입력 유예, 공격 중 대시, 적의 준비와 빈틈, 기본 공격 6, 빈틈 피해 1.5배, 수문장/지역 보상/보급품/상점/체크포인트를 유지했습니다.

돌진은 1.2초·4단계 집중 후 자동 발동하며, 수정용 쿨타임 1초, 기본 피해 20/빈틈 30, 집중 중 이동 금지와 조기 해제 취소를 유지합니다. 키 설정/물약 단축키/스테이지 페이드도 유지했습니다.
