## 원인과 수정

기존 대기 캐릭터는 선 자세이고 새 발도 캐릭터는 웅크린 자세인데, 새 포즈를 전체 높이 76 게임 단위로 표시해 머리와 갑옷이 더 크게 보였습니다. 실제 게임에서 두 포즈를 같은 바닥선과 카메라 배율로 나란히 렌더링해 확인했습니다.

발도 시트의 표시 몸 높이를 76에서 61로 낮췄습니다(약 19.7% 축소). 준비·부분 발도·베기·후속 자세·납도·납도 후 대기의 6포즈 모두 동일한 배율을 사용합니다. 선 자세와 웅크린 자세는 높이가 자연스럽게 다르지만 머리와 갑옷의 크기를 맞췄습니다.

시트를 새로 그리거나 원본 PNG를 줄이지 않고 표시 배율을 수정했습니다. 발 기준은 그대로 유지하고 칼집의 빛 좌표는 같은 배율을 따르므로 새 몸 크기에 맞게 자동 보정됩니다. 이펙트 크기와 실제 공격 범위/피해/충전 시간은 유지합니다.

- 코드: core/src/main/java/com/example/pixelgame/IaiSprites.java
- 크기 설정: assets/player/iaido-layout.properties, renderBodyHeight=61
- 비교 화면: Deadlight_iaido_size_compare_1103.png (위: 수정 전, 아래: 수정 후)

## 검증

Java/Gradle 컴파일 통과. 실제 OpenGL 창에서 평상시/준비/발도/납도 후 포즈를 동일한 카메라로 렌더링해 비교했습니다. 기존 자동 입력 검사도 재실행하여 지면과 발판의 발 위치, 좌우 반전, 30/60/120fps의 2초 자동 발동, 전방 적 각 20 피해, 뒤쪽/범위/높이 제외, 이동 차단, 조기 해제, 키 재지정, 화면 버튼, 피격/일시정지 처리와 GL 상태 복원을 확인했습니다.

검증은 자동 입력과 상태 구성을 사용했으며 사용자의 설정/기록을 저장하지 않았습니다. 변경 전 코드와 메타데이터는 work/iaido-size-1103/source-before에 보존했습니다.
