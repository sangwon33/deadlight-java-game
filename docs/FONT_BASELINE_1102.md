# 한 줄 안의 글자 높이 불균일 수정

적용 프로젝트: `C:\Users\USER\Desktop\Java\Deadlight`

문구의 배치와 별도로, 18px 비트맵 글꼴을 소수 배율로 축소하면서 글자별 좌표와 크기를 정수로 반올림해 기준선에 오차가 발생했습니다. 이전 UI 배치 수정에서는 이 문제를 해결하지 못했습니다.

- 글꼴을 72px로 생성하고 기존 표시 크기로 축소해 작은 한글의 형태와 획을 개선했습니다.
- BitmapFont의 글자별 정수 좌표 반올림을 끄고 소수 좌표와 공통 기준선을 유지합니다.
- UiTypography에서 표시 배율을 통일했습니다. 메뉴, 상점, HUD, 스테이지 제목 및 전투 숫자에 함께 적용했습니다. 기존 표시 크기와 배치는 유지합니다.
- 작게 축소된 글자에 짙은 그림자가 겹치지 않도록 그림자를 조정했습니다.

검증: 실제 OpenGL 실행에서 같은 문장을 기존 방식/소수 좌표/고해상도 글꼴로 비교했습니다. 6개 표시 크기의 한글·영문·숫자·기호에 대해 글리프 정점에서 계산한 기준선 오차는 반올림 시 최대 0.5 월드 단위였으며, 수정 후 0.00001 미만입니다. 실제 UI를 1280×720 및 960×540에서 렌더링하고 글자 영역 검사도 통과했습니다.

이미 실행 중인 게임에는 적용되지 않으므로 게임을 종료한 후 Eclipse에서 F5를 누르고 다시 실행하세요.
