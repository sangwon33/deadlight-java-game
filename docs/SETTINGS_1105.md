## 조작과 저장

- 마우스로 탭·항목·좌우 화살표·아래 버튼을 누릅니다.
- ↑↓로 항목과 하단 버튼 선택, ←→로 값 조절, Enter로 실행합니다.
- Tab / PageDown은 다음 탭, PageUp은 이전 탭입니다. Esc는 이전 화면으로 돌아갑니다.
- 이 탭 초기화는 현재 분류만 복원합니다. 설정 초기화는 확인창을 거쳐 26개 설정을 복원하며 기본 선택은 취소입니다.
- 키 설정에서 기존 행동별 키 변경을 제공합니다. 설정 초기화와 키 기본값 복원은 분리했습니다.
- 기존 음량·음소거·화면 버튼 값은 이어 사용합니다. 유효한 행동 키와 클리어 기록은 유지합니다. 기록 규칙은 rules6입니다.
- 다른 창으로 전환하면 입력/차징/살펴보기 예약을 해제합니다. 자동 멈춤을 사용한 경우 돌아와도 사용자가 재개할 때까지 일시정지를 유지합니다.
