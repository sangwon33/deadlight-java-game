## 동작

- 기본 Q를 누르면 새 발도 준비 자세를 취합니다. 설정에서 변경한 스킬 키와 화면 버튼도 지원합니다.
- 지상에서 2초 동안 충전합니다. 단계는 0~0.5초 / 0.5~1초 / 1~1.5초 / 1.5~2초의 4단계입니다.
- 칼집과 칼이 만나는 위치에 흰색 → 하늘색 → 보라색 → 금색 빛이 생기며 크기와 입자 밀도가 커집니다.
- 2초가 되면 키를 계속 누르고 있어도 즉시 자동 발동합니다. 섬광, 전방 검기, 금속성 발도음 뒤 납도 동작으로 이어집니다.
- 전방 180 게임 단위, 플레이어 높이 부근의 적 각각에게 임시 고정 피해 20을 한 번 줍니다. 뒤쪽·높이 밖·범위 밖 대상은 제외합니다. 보스도 20입니다.
- 충전 중 이동·점프·공격·대시·방향 전환을 막습니다. 발도·납도 약 0.46초도 제자리를 유지합니다.
- 일찍 놓으면 공격 없이 취소합니다. 발동 후 쿨타임 8초는 유지했습니다. 피격 시 취소 및 쿨타임이 적용되고, 메뉴/포커스 전환은 저장된 충전을 취소합니다.
- 안내 문구, HUD의 남은 시간과 4단계 바, 튜토리얼, 키 설정 이름, 인벤토리 설명을 함께 변경했습니다.

## 검증

Java/Gradle 컴파일 및 실제 libGDX/OpenGL 창에서 자동 입력 검증을 통과했습니다.

- 30/60/120fps에서 2초 자동 발동, 4단계, 키 유지 시 중복 타격 방지
- 전방 여러 적 각 20 피해, 뒤쪽/범위/높이 제외, 좌우 방향, 보스 30→10 HP
- 충전 이동/점프/공격/대시 차단, 발판 위 발 위치, 조기 취소, 피격/일시정지/공중 처리
- 키 재지정 및 화면 버튼 유지/드래그, 연출의 GL 상태 복원
- 6단계 튜토리얼 및 본편 진입, 상점, 보상/체크포인트, 보스 처치, 결과/기록, 한글 UI 회귀 검사
- 실제 게임 렌더링 60프레임 GIF 확인

검증은 상태 구성과 자동 입력을 조합했으며, 사람이 전체 게임을 수동 플레이한 검사는 아닙니다. 테스트는 메모리 내 설정/기록을 사용하고 오디오 장치는 비활성화했으므로, 실제 스피커에서의 효과음 청취는 미검증입니다.
