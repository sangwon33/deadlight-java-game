# 위·아래 시야 확보 — 2026-11-04

## 조작과 동작

- W 또는 ↑를 0.65초 유지하면 위쪽을, S 또는 ↓를 유지하면 아래쪽을 부드럽게 살펴봅니다.
- 기본 추적 위치에서 세로 최대 144만큼 이동하며 맵의 위/아래 경계를 넘지 않습니다.
- 키를 놓으면 원래 추적 위치로 부드럽게 복귀합니다. 짧게 누르기를 여러 번 해도 대기 시간이 누적되지 않습니다.
- 위·아래를 동시에 누르면 둘러보기를 해제합니다. 반대 방향으로 바꾸면 0.65초를 다시 기다립니다.
- S/↓는 기존 웅크리기와 얇은 발판 한 칸 내려가기도 수행합니다.
- 설정 → 키 설정의 ‘위 보기’와 ‘웅크리기 / 내려가기’를 변경하면 살펴보기에도 적용됩니다. 방향키 보조 입력은 기본 키를 사용하는 동안만 적용되며, 다른 행동에 직접 지정한 방향키가 우선합니다.
- 메뉴/가방/상점/보상/Tab 지도/지역 전환에서는 둘러보기 입력을 쌓지 않습니다. 일시정지 후에도 대기 시간을 다시 시작합니다. 새 지역/재도전에서 카메라 둘러보기 상태를 초기화합니다.
- HUD는 화면에 고정됩니다. 카메라만으로 본 곳은 탐색 지도에 기록하지 않습니다. 실제 방문 규칙은 유지합니다.

## 구현

- CameraLook.java: 연속 입력 지연, 방향 전환/충돌 처리, 프레임률과 무관한 지수 보간.
- Main.java: 기존 양축 추적에 세로 오프셋 합산, 지상 위쪽 시야 제한 보정, 맵 경계 제한, 메뉴별 활성 조건.
- KeyBindings.java: 기존 열거형 뒤에 LOOK_UP을 추가해 기존 저장 키를 보존하고 W/↑와 S/↓를 연결.
- 키 설정은 13개 행동이 두 열 안에 들어가도록 배치했고 튜토리얼 이동 안내에 둘러보기를 추가했습니다.

## 검증

실제 LWJGL/OpenGL 게임 창에 분리된 누름/유지/해제 입력과 메모리 설정을 주입하여 확인했습니다. 사용자 저장 설정은 수정하지 않았습니다.

- 30/60/120fps의 0.65초 지연, 짧은 누름, 연속 유지, 방향 전환, 동시 입력, 부드러운 복귀.
- 실제 게임의 S 웅크리기/방향키 발판 내려가기, 지상 위 보기 제한 해제, 5개 지역의 카메라 경계.
- 메뉴/지도/일시정지의 대기 시간 초기화, 지역 전환 초기화, 저장된 W 키 이관/재설정.
- 13개 키 설정 항목의 화면 내 배치와 실제 렌더링.
- 카메라를 움직여도 미탐색 지도 칸이 공개되지 않음.
