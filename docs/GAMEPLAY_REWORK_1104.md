# DeadLight 플레이 흐름 개편 — 2026-11-04

## 이번 수정의 방향

기존의 스테이지형 액션 구조를 유지하면서, 이동 → 공격 읽기 → 회피 → 반격 → 선택 경로 탐색 → 수문장 처치 → 상점/지역 보상 → 다음 지역이 이어지도록 구성했습니다. 연결형 오픈 월드로 바꾸거나 새 캐릭터 에셋을 만들지는 않았습니다.

적용 위치는 C:/Users/USER/Desktop/Java/Deadlight 입니다. 다운로드 폴더의 다른 컴퓨터 백업은 변경하지 않았습니다.

## 조작과 이동

- Space를 짧게 놓으면 낮게, 계속 누르면 높게 점프합니다. 화면 점프 버튼도 누르는 시간을 반영합니다.
- 발판을 막 벗어난 뒤 0.10초 동안 점프할 수 있고, 착지 직전 0.12초 안에 누른 점프는 착지와 함께 실행합니다.
- 내려오는 도중 여러 발판을 통과하면 먼저 닿는 가장 높은 발판에 착지합니다.
- 대시 재사용은 5초에서 0.65초로 줄였습니다. 공격 동작을 대시로 취소할 수 있고, 공중 대시는 착지 전 한 번 가능합니다.
- 방향 키와 대시를 동시에 눌렀을 때 현재 입력한 방향으로 대시합니다.
- 대시 거리는 프레임 속도와 관계없이 112입니다. 이동 260/초, 대시 800/초는 유지했습니다.
- 일반 공격 종료 직전에 누른 다음 공격을 0.12초 동안 기억합니다. 스킬에는 이 예약 입력을 적용하지 않습니다.

## 전투 규칙

| 항목 | 현재 값/행동 |
| --- | --- |
| 플레이어 기본 체력 | 100, 적/보스 기본 피격 20 |
| 기본 일반 공격 | 6 + 공격 강화 단계 + 공격 물약 보너스 |
| 일반 슬라임 / 기사 / 검은 슬라임 | 체력 18 / 36 / 24 |
| 수문장 | 체력 최소 36, 머리 위에 표시 |
| 타락한 신 | 체력 120 |
| 기사 정면 방어 | 일반 공격 피해 절반(올림), 경직 방지 |
| 기사 후방 / 돌진 | 후방 일반 공격은 정상 피해, 돌진은 정면 방어 해제 |
| 공격 후 빈틈 | 해당 시간에 받는 피해 1.5배 |
| 돌진 찌르기 | 기본 20, 빈틈 반격 시 30 |

적은 공격 방향을 정한 뒤 준비 표시와 공격 범위 선을 보여주며, 공격 도중 플레이어 방향으로 즉시 뒤집지 않습니다. 공격 뒤에는 파란 빈틈 표시와 남은 시간을 보여주고 추적을 잠깐 멈춥니다.

기사의 헛친 공격 뒤 빈틈은 1.75초입니다. 실제로 피해를 준 공격 뒤 빈틈은 그 55%이므로, 회피 성공이 긴 반격 기회로 이어집니다. 초록 슬라임의 빈틈은 더 짧아 빠른 일반 공격에, 기사는 집중 후 돌진 반격에 적합합니다.

타락한 신은 정면 찌르기 → 하단 공격 → 상단 공격 → 광역 베기를 반복합니다. 준비는 0.55초, 체력 절반 이하에서는 0.42초이며 공격 뒤 1.5초(광역 1.75초)의 반격 기회를 줍니다.

기존의 발견 후 지속 추적은 유지했습니다. 높은 곳의 경비병은 발판 범위 안에서 배회하고, 지상의 적도 높은 플레이어 아래에서 왕복 이동합니다.

## 지역 구성과 목적

| 지역 | 구성 |
| --- | --- |
| 조작 훈련 | 기존 6개 과제 유지, 가변 점프/새 대시 설명 반영 |
| 신록의 폐허 | 슬라임 거리 익히기 → 기사 회피/반격 → 높은 길 보급 → 기사 수문장 |
| 성벽 | 정면 방어 기사, 높은 길의 경비병, 우회 경로와 수문장 |
| 잿빛 전장 | 준비가 빠른 검은 슬라임, 경비병과 보급 경로, 마지막 수문장 |
| 여신의 교회 | 4종 순환 공격을 배우고 빈틈에 반격하는 보스전 |

1~3지역마다 발판 6개, 적 5명, 수문장 1명, 보급품 2곳을 배치했습니다. 위쪽 보급품은 접촉하면 한 번 획득하며 골드와 회복/공격 물약을 제공합니다. 높은 길은 선택 경로입니다.

수문장을 처치해야 출구 봉인이 풀립니다. 출구와 HUD가 현재 목표를 표시하며, 구간 첫 진입 시 짧은 한글 안내가 나옵니다. 수문장 이외의 모든 적을 반드시 처치할 필요는 없습니다.

1~2지역 배경의 채도와 밝기를 조금 낮췄고, 3지역 발판은 잿빛 배경에 맞춰 채도와 색을 조절했습니다. 원본 이미지 파일은 그대로이며 렌더링에만 적용됩니다.

## 유지한 최근 요청과 기존 기능

- 캐릭터 크기 0.8 및 몸/공격 판정 비율.
- 최신 양손 준비 자세와 현재 돌진 스프라이트.
- 1.2초/4단계 집중 → 자동 돌진, 집중 중 이동 금지, 일찍 놓으면 취소.
- 수정용 스킬 재사용 1초, 돌진 거리 210/0.22초, 전체 동작 0.38초.
- 플레이어 스킬 전용 이펙트와 효과음 없음.
- 저장 가능한 키 설정, 한글 UI/폰트 기준선, 고정 화면 HUD, 포션 단축키, 상점 상호작용 키 표시.
- 상점, 인벤토리, 지역 보상 선택, 진입 체크포인트, 통계/결과, 화면 전환 페이드.

재도전하면 보급품 획득 여부와 인벤토리/골드를 지역 진입 시점으로 함께 돌립니다. 실패한 시도에서 챙긴 보급품을 중복 누적할 수 없습니다.

적 체력과 공격력 규칙이 달라졌으므로 클리어 기록은 rules2 이름으로 분리합니다. 이전 기록 데이터는 삭제하지 않았으며, 개편판 화면은 새 규칙의 기록을 표시합니다.

- RegionGuide.java: 보급품 획득과 구간별 안내, 재도전 시 초기화.

- Player.java / Enemy.java / FallenGod.java: 이동과 각 전투 상태.
- Main.java: 공통 지역 데이터를 사용한 생성/진행, 보급품 지급, 수문장 출구 조건.
- 나머지 UI/기록 클래스: 현재 규칙 안내와 기록 버전 반영.

- 6개 튜토리얼 과제, 출구 봉인, 상점/포션, 20 피해/피격 무적, 체크포인트 복원, 지역 보상, 보스 처치, 결과/기록, 키 변경/저장 확인.

- 한글 HUD·준비/빈틈 표시·보급 안내·보스 화면을 렌더링해 육안 확인.

상점/보상/사망 등의 상태 검사는 적 제거와 위치 설정을 함께 사용했습니다. 사람이 처음부터 끝까지 수동으로 완주한 검사는 아니며, 장시간 플레이에 따른 최종 난이도와 오디오는 별도로 검증하지 않았습니다.
