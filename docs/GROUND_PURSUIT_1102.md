# 지면 접촉과 몬스터 추적 수정

적용 프로젝트: `C:\Users\USER\Desktop\Java\Deadlight`

- TerrainTile에서 이미지의 연속된 표면을 계산해 실제 착지 높이에 맞춰 그립니다. 나무 발판 위쪽 투명 여백(724px 중 245px)과 1지역 지면의 상단 여백(1254px 중 29px)을 보정했습니다. 나무 발판 좌우의 투명 여백도 표시 영역에서 제외해 타일 사이의 틈을 줄였습니다.
- 지면 네 종류와 나무 발판에 적용했습니다. 캐릭터의 발 기준과 실제 착지/낙하 판정 높이에 바닥 그림이 맞춰집니다.
- 슬라임·기사·검은 슬라임이 아직 플레이어를 발견하지 않았을 때도 생성 위치 근처에서 느리게 배회합니다.
- 한 번 플레이어를 발견하거나 피해를 받으면 추적 상태를 유지합니다. 화면 밖 또는 최초 감지 거리 밖으로 멀어져도 해당 지역에서 추적을 계속하고, 플레이어가 반대쪽으로 이동하면 방향을 바꿉니다.
- 플레이어가 높은 발판에 올라가 공격 높이가 맞지 않을 때는 아래에서 이동 속도 40%로 배회합니다. 공격이 닿는 높이로 돌아오면 접근/공격을 재개합니다.
- 월드 좌우 끝 경계를 지킵니다. 추적 상태는 적 사망 또는 지역 재시작/이동으로 적이 새로 생성될 때 초기화합니다. 튜토리얼 연습용 표적은 기존처럼 수동적입니다.

수정 소스: `Main.java`, `Enemy.java`, `TerrainTile.java`.

검증: 실제 OpenGL 실행에서 지면/발판 접촉과 네 지역 바닥을 렌더링해 확인했습니다. 실제 플레이어 물리 업데이트로 낙하 후 발판 착지와 걸어서 내려온 뒤 지면 착지를 확인했습니다. 세 몬스터 종류 모두 감지 전 배회, 감지 거리 밖 추적, 추적 방향 전환, 높은 표적 아래 왕복 이동, 높이 차이로 인한 공격 방지, 착지 후 20 피해 공격 재개, 좌우 월드 경계 검사를 통과했습니다. 기존 튜토리얼·보상·재도전·상점·보스·기록·키 설정 자동 실행 검사도 통과했습니다. 검증에는 메모리 Preferences를 사용했습니다.

실행 중인 게임을 닫고 Eclipse에서 F5로 새로고침한 뒤 다시 실행하세요. 통합 ZIP에도 변경을 반영했습니다.
