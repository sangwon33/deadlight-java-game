# 일시정지 키보드 조작·차징 스킬 — 2026-11-24

이 문서의 스킬 수치가 이전 기록보다 우선합니다.

- 일시정지 메뉴에서 ↑↓ 또는 W/S로 선택하고 Enter로 실행합니다. Esc는 계속하기입니다. 선택 위치에 기존 은빛 강조를 표시합니다.
- 재시작·메인 메뉴는 취소/확인 창을 거칩니다. 기본 선택은 취소이며 ↑↓/←→ 또는 W/S로 바꾸고 Enter로 결정합니다. Esc로 취소하면 원래 메뉴 선택을 복원합니다.
- 마우스 이동·클릭을 계속 지원합니다. 정지한 커서는 키보드 선택을 덮어쓰지 않으며 설정에서 돌아오면 선택을 유지합니다.
- 정신집중은 1.2 → 1.0초, 총 4단계이며 완료 시 자동으로 돌진합니다. 조기 해제 취소·차징 중 이동 불가를 유지합니다.
- 재사용 대기시간은 발사 시점부터 1 → 5초입니다. 피격으로 차징이 끊겼을 때도 5초가 적용됩니다.
- 찌르기는 기본 20 → 40, 공격력 강화 1회당 추가 피해 +3 → +6입니다. 기존 강화·힘 포션·치명타 조건에서 계산되는 피해를 2배로 합니다. 기본 힘 포션 적용 시 80, 힘 포션과 치명타 적용 시 160입니다.
- 튜토리얼·기술 설명·스탯·재사용 게이지는 공유 상수와 실제 플레이어 수치를 사용합니다. 변경 규칙의 클리어 기록은 rules11로 분리하며 이전 기록을 삭제하지 않습니다.
- 직전 수정: 지역 선택 화면은 실제 4개 지역만 순회하고 돌아가기를 분리합니다. 미리보기 번호도 유효 범위로 제한합니다.

## 검증

실제 LWJGL 실행에 입력을 주입해 일시정지의 계속하기·설정 복귀·재시작·메인 메뉴·취소/확인과 마우스 혼용을 검증합니다. 30/60/120fps에서 4단계·1초 자동 발사·이동 잠금·5초 쿨타임·재입력·취소·피격 중단·준비 알림을 확인합니다. 실제 표적에 대한 기본 피해 40과 힘 포션+치명타 피해 160, 강화별 수치, 두 해상도 및 큰 글씨 표시를 검사합니다.
