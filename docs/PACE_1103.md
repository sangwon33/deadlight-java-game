## 변경 수치

- 플레이어(대기·이동·점프·공격·대시·새 스킬 6포즈), 슬라임·기사·검은 슬라임, 보스의 모든 지원 동작, 상점 NPC를 이전의 0.8배로 표시합니다.
- 플레이어/적/보스의 피격 몸 크기와 근접 공격 범위도 0.8배로 맞춥니다. 발 위치와 각 프레임의 지면 오프셋을 같은 비율로 보정합니다.
- 상점 아이콘을 줄어든 NPC의 머리 위로 옮기고 상호작용 중심도 맞췄습니다. 글자/HUD/메뉴 크기는 유지합니다.
- 플레이어 이동: 200 → 260 게임 단위/초 (+30%).
- 플레이어 대시: 650 → 800 게임 단위/초 (약 +23%).
- 달리기 애니메이션은 이동 속도와 줄어든 보폭에 맞춰 빠르게 재생합니다.
- 집중 시간: 2.0 → 1.2초 (4단계 유지, 각 단계 약 0.3초).
- 돌진 이동: 0.30 → 0.22초. 이동 거리 210을 유지하도록 속도를 약 954.5 단위/초로 높였습니다.
- 돌진과 회복 전체: 0.56 → 0.38초. 발진·찌르기·제동·회복의 프레임 전환도 함께 단축했습니다.
- 피해 20과 스킬 재사용 8초, 조기 취소, 피격 취소, 키 변경/화면 버튼을 유지합니다. 스킬 전용 이펙트는 추가하지 않았습니다.
- HUD 남은 초, 튜토리얼, 인벤토리 안내를 실제 충전 시간에서 계산하도록 연결했습니다.

크기와 속도는 GameBalance.java의 CHARACTER_SCALE, PLAYER_MOVE_SPEED, PLAYER_DASH_SPEED 및 SKILL_* 상수에서 조정할 수 있습니다.

## 검증

Java/Gradle 컴파일 및 실제 libGDX/OpenGL 실행 자동 입력 검증을 통과했습니다.

- 실제 SpriteBatch에 전달된 플레이어/스킬 6포즈의 출력 크기와 발 기준 확인
- 일반 적 3종의 대기·이동·공격 및 지원되는 사망 프레임, 보스 5가지 상태의 출력 크기가 0.8배인지 확인
- 플레이어/적/보스의 줄어든 피격 판정 및 보스 공격 범위 확인
- 실제 입력으로 이동 260/초와 대시 800/초 확인
- 1.2초 집중과 4단계, 30/60/120fps에서 동일한 210 돌진 거리
- 전방 적 각 20 피해, 중복 타격 방지, 뒤쪽/높이/범위 제외, 보스 30→10 HP
- 좌우, 맵 경계, 지면/발판, 키 재지정/화면 버튼, 조기 해제/피격/일시정지/공중 처리
- 튜토리얼 전체, 본편 진입, 상점, 보상/체크포인트, 결과/기록, 보스 전투 회귀 검사
- 축소된 상점 NPC/보스 실제 화면과 1000×360, 50프레임, 20fps 미리보기 확인
