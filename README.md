# Deadlight

Java 17 이상 / libGDX 데스크톱 2D 액션 탐색 게임.

현재 버전은 2026-11-24 이동·포션·설정 조정판입니다. 최신 변경과 검증은 docs/PACE_SETTINGS_1124.md, 지역 밸런스는 docs/PROGRESSION_1124.md, 이전 UI 개편은 docs/OVERHAUL_1124.md, 팀원 전투·맵 연결은 docs/TEAM_MERGE_1106.md를 참고하세요.

## 실행

프로젝트 폴더에서 `gradlew.bat lwjgl3:run` 또는 `PLAY.cmd`를 실행합니다.
Eclipse에서는 F5로 새로고침한 뒤 Gradle Tasks → lwjgl3 → application → run을 실행합니다.

## 기본 조작

| 키 | 행동 |
|---|---|
| A / D | 이동 |
| Space | 점프 — 짧게/길게 누름에 따라 높이 변화 |
| J | 지상 3타 베기 — 다시 눌러 가로/올려/전진 내려베기, 공중 공격 유지 |
| Shift | 대시 — 공격 중 취소 가능, 지상 대시에서 점프 연계, 공중 1회 |
| Q | 1.2초/4단계 정신집중 후 자동 돌진 찌르기 — 일찍 놓으면 취소 |
| W / ↑ | 가만히 서서 위 보기 — 0.65초 유지 시 시야 이동 |
| S 짧게 눌렀다 놓기 | 얇은 발판·승강기 한 칸 아래로 |
| S 0.65초 이상 유지 | 엎드려 아래 살펴보기 — 놓으면 시야 복귀 |
| E | 상점 / 회복 우물 / 중간 보스 상호작용 |
| I | 가방 |
| 1 / 2 / 3 | 회복 / 공격력 / 신속 포션 |
| 상점에서 ↑↓ 또는 W/S, Enter 또는 Space | 물품 선택, 구매 |
| Tab | 누르는 동안 탐색 지도·플레이어 스탯 확인 및 일시정지 |
| Esc | 일시정지 |

설정 → 키 설정에서 행동별로 변경하며 안내는 현재 키를 표시합니다. 가만히 서서 S를 누르면 전용 엎드린 에셋이 즉시 표시되고, 아래 시야는 0.65초 후부터 이동합니다. S의 짧은 입력은 키를 뗄 때 내려가기를 실행하며, 길게 누른 뒤 뗄 때는 떨어지지 않습니다. ↓의 아래 보기와 ↓+점프 조합은 제거했습니다. 키 설정의 ‘내려가기 / 아래 보기’에서 통합 키를 변경할 수 있습니다. 위 보기의 ↑ 보조 키는 기본 W 설정을 쓰는 동안만 적용됩니다.

## 팀원 전투 기능

J 연속 입력으로 3타 베기를 연결합니다. 기본 피해는 6 / 6 / 8이며 3타는 20픽셀 전진하고 강공격입니다. 누르고 있기만 해서는 연타하지 않습니다. 1·2타 중 대시 취소, 3타는 0.30초 이후 취소가 가능합니다. 키 설정/화면 버튼과 기존 Q를 함께 지원합니다.

일반 지역마다 선택형 중간보스가 있습니다. 1지역 뿌리 예배당의 순례자(108HP), 2지역 등불 감시탑의 등불지기(233HP), 3지역 봉합자의 정원의 봉합자(422HP)입니다. 상층 길의 새 발판과 바깥 발코니로 올라가 입구에서 E로 도전합니다. 보상은 각각 60/80/100G와 공격력 +1, 포션 1개입니다. 수문장과는 별개이며, 도전한 방은 처치할 때까지 닫힙니다. 지도에는 직접 방문한 시련만 표시합니다.

최종보스는 일식의 처형자(843HP, 피해 102~119)로 바뀌며 대검 4패턴과 체력 절반 이후 격화를 사용합니다. 가면 나방과 등불 사수를 추가해 일반 지역 적은 15/18/19마리입니다. 밀집 맵 폭은 유지하고 일반 지역의 고정 발판을 선택 방 포함 58/57/55개로 늘렸습니다. 새 기록은 rules10이며 이전 기록을 보존합니다. 상세: docs/TEAM_MERGE_1106.md.

## 설정

로비 또는 Esc → 설정에서 소리·화면·표시·조작·접근성 5개 탭, 26개 항목을 조절합니다. 전체 음량, 밝기/창 크기/VSync/FPS, 미니맵·피해 숫자·적 체력바·공격 예고, 길게 누르기 시간/시야 범위, 큰 글씨/섬광 완화/외곽 강조 등을 제공합니다. 기본 길게 누르기 시간은 0.65초이며 0.50/0.80초로도 바꿀 수 있습니다. 마우스 또는 ↑↓/←→/Enter로 조절하고 Tab으로 탭을 옮깁니다. 변경은 즉시 자동 저장하며, 초기화 확인창과 행동별 키 설정을 제공합니다. 상세: docs/SETTINGS_1105.md.

## 플레이

폭 1000(약 1.56화면)의 고정 허수아비 훈련장에서 7과제를 마친 후 신록의 폐허 → 성벽 → 잿빛 전장 → 여신의 교회로 진행합니다. 세 지역은 가로 3000/3200/3400의 밀집 구조로, 지하 샛길·상층 탑·보급품·바람·승강기·가시가 이어집니다. 수문장을 처치하고 출구에 도착하면 지역 보상을 고릅니다.

체력 100, 기본 피격 피해 20, 일반 공격 6, 돌진 20입니다. 수문장은 크기 1.5배이며 붉게 빛납니다. 지역별 체력은 54/87/136, 공격력은 30/50/84입니다. 피해 구간은 붉은 체력 잔상으로 남았다가 천천히 줄어듭니다. 적 공격 후 빈틈에는 1.5배 피해를 줍니다. 지상에서만 사용할 수 있는 돌진 찌르기는 현재 수정/검토용 재사용 1초를 유지합니다. 플레이어와 모든 캐릭터는 기존 크기의 80%입니다.

살펴보기에는 새 전용 자세를 사용하고 캐릭터가 화면 안에 남는 선에서 위/아래 이동량을 72/148로 확대했습니다. 실제 에셋 외곽을 기준으로 맵 양끝에서도 몸과 검이 잘리지 않게 합니다. 실제 방문한 주변만 미니맵/Tab 지도에 기록하며, 카메라로 둘러보기만 한 곳은 기록하지 않습니다. 탐색 기록은 현재 모험의 재도전에서 유지하고 새 모험에서 초기화합니다.

기본 이동속도는 238로 이전 340보다 30% 낮췄고, 점프 시작 속도는 744로 이전 930보다 20% 낮췄습니다. 신속 효과 중 이동속도는 357입니다. 튜토리얼의 아래쪽 착지 발판은 160 높이로 보정했습니다. 각 일반 지역에 고정 발판 58/57/55개와 건축물/사슬 지지물이 있습니다. 무너지는 발판, 분출 함정, E로 한 번 쓰는 회복 우물을 추가했습니다. 보급품은 바닥의 가방/상자로 표시합니다.

플레이 HUD 왼쪽 위에는 체력바와 골드·회복·공격력·신속 포션 목록, 그 아래 선택형 스탯창을 묶었습니다. 오른쪽 위에는 일시정지와 미니맵을 배치했습니다. 스킬이 사용 가능해지면 슬롯에 빛과 짧은 준비 알림이 뜹니다. 큰 화면 조작 버튼은 기본으로 끄며 필요하면 설정에서 켤 수 있습니다. 상세 시간/전투 통계는 결과 화면에서 확인합니다.

체력바는 구분선 없이 양끝을 둥글게 채우며 은색 원형 장식 안의 루비색 하트를 사용합니다. 회복 포션은 붉은 내용물로 표시합니다. 회복 성공 시 약 0.9초간 빨간 오라, 공격력·신속 포션은 실제 남은 효과 시간 동안 보라·초록 오라가 캐릭터를 따라갑니다. 섬광 완화 설정을 함께 적용합니다. 제작·구현 상세: docs/POTION_AURA_1124.md.

공격·찌르기·대시 아이콘에 마우스를 올리면 현재 지정 키와 기술 설명·피해·쿨타임을 표시합니다. 공격·점프·대시·포션 사용에는 짧은 슬롯 빛 반응을 넣었으며, 섬광 완화 설정을 함께 적용합니다. 차징 단계 안내는 찌르기 슬롯 위에 표시합니다.

허수아비의 직전 타격·DPS·누적 Total 통계창은 제거했습니다. 일반 피격 피해 숫자는 유지합니다. 허수아비 체력은 100,000이며 넉백이 없습니다. 공격 과제는 지상 3타 동작 완료로 판정하고, 완료 표시를 0.75초 보여준 뒤 진행합니다. 삼각형 이전·다음 버튼으로 완료한 설명을 다시 볼 수 있습니다.

일반 적과 중간보스의 골드는 처치 위치에서 바닥으로 떨어진 뒤 1.5초부터 플레이어에게 날아와 약 1.75초에 자동 획득됩니다. 획득 시 코인 표시의 빛·증가량과 짧은 획득 효과로 알립니다. 지도·메뉴에서는 획득 시간이 멈추며, 지역 이동 전에 남은 재화를 회수합니다.

포션 옆 안내는 현재 지정된 사용 키를 은색 테두리 키캡으로 표시합니다. 숫자 크기를 통일하고 HUD의 ‘사용’ 문구를 제거했습니다. 가방에도 키캡을 적용했습니다. Tab 지도 옆에서는 공격력, 이동속도, 공격속도, 크리티컬 확률·피해 배율과 스킬 공격력·스킬/대시 쿨타임을 확인할 수 있습니다. 설정 → 표시 → ‘스탯창 상시 표시’를 켜면 체력을 제외한 기본 5개 항목이 아이템 목록 아래 아이콘·수치로 표시됩니다. 아이콘에 마우스를 올리면 항목 이름을 확인할 수 있습니다. 공격력은 강화와 포션 효과를 즉시 반영하며, 공격속도는 지상 3타 연계 기준입니다. 기본 치명타 확률은 20%, 피해 배율은 200%이며 실제 일반 공격·찌르기에 적용합니다. 치명타 피해 숫자는 빨간색입니다. 공격력 포션은 5초간 일반 공격·찌르기 피해를 2배, 신속 포션은 5초간 이동속도를 1.5배로 합니다. 중복 사용 시 효과는 중첩하지 않고 5초로 갱신하며, 신속 포션은 상점과 공격·신속 보급품에서 얻습니다.

몬스터 총 보상의 90%를 공격·체력 강화에 비슷한 금액으로 누적 지출한 기준으로 다음 지역의 몬스터·보스 체력과 피해를 고정 조정합니다. 체력 강화는 40골드에 +20이며, 공격력 강화 1회마다 찌르기 피해도 +3입니다. 회복 포션은 최대 체력의 30%를 회복합니다(정수 반올림, 최대 체력 상한 적용). 지역 선택으로 바로 시작할 때는 해당 지역 기준 강화 상태를 제공합니다. 상세 수치와 예산은 docs/PROGRESSION_1124.md에 있습니다.

상점/지역 보상/지역 진입 체크포인트/재도전/설정 자동 저장을 지원합니다. 통합 규칙의 기록은 rules10이며 이전 기록을 보존합니다. 앱 종료 후 진행 중 모험을 이어 하는 저장 기능은 아직 없습니다.
