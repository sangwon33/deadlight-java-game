# Deadlight

현재 프로젝트 경로: `C:\java game\Deadlight`. 실행은 이 폴더의 `PLAY.cmd`를 사용합니다. 소스는 `core/src/main/java`, 에셋은 `assets`에 있습니다.

Java 17 이상 / libGDX 데스크톱 액션 게임.

최신 탐색 개편: 이동 340/초·대시 960/초(0.42초 재사용), 공격→대시→점프 연계. 1~3지역을 가로 약 2~2.5배와 수직 탐색 공간으로 확장했습니다. S는 웅크리기/발판 아래로, E는 상점/레버 상호작용, Tab을 누르는 동안 일시정지 지도를 봅니다. 바람·승강기·레버/석문·가시와 7과제 튜토리얼을 추가했습니다. 상세: docs/TRAVERSAL_1104.md.

최신 UI: 떠 있는 글자 메뉴의 로비, 은청색 장식, 얇은 HUD, 세로형 일시정지 메뉴와 통일된 상점/가방/보상/설정. 로비에서는 ↑/↓ 또는 W/S로 선택하고 Enter로 결정할 수 있습니다. 상세: docs/LOBBY_UI_1104.md.

최신 아트: 은청색 뿌리 동굴/성벽/보랏빛 정원/침묵의 성당과 손그림풍 가면 검객·적·보스·상점·아이템을 적용했습니다. 이미지와 연결 방식, 검증: docs/MOONLIT_ART_1104.md. 제작 프롬프트: docs/MOONLIT_ART_PROMPTS_1104.md.

2026-11-04 플레이 흐름 개편: 적의 준비 동작을 읽고 대시로 피한 뒤 빈틈에 반격합니다. 1~3지역에서 높은 길의 보급품을 챙기고, 수문장을 처치해 출구 봉인을 풀면 상점/지역 보상과 함께 다음 지역을 준비할 수 있습니다. 상세 설계·수치·검증: docs/GAMEPLAY_REWORK_1104.md.

점프는 짧게/길게 누르기에 따라 높이가 바뀝니다. 대시 재사용은 0.42초이며 일반 공격 중에도 회피할 수 있습니다. 지상 대시에서 점프로 이어갈 수 있으며 공중 대시는 착지 전 한 번입니다. 기본 공격 6, 돌진 20, 적의 빈틈에는 피해 1.5배(돌진 30)입니다.

실행: 프로젝트 폴더에서 `gradlew.bat lwjgl3:run` 또는 `PLAY.cmd`.

Eclipse: Gradle 프로젝트로 가져온 뒤 lwjgl3 → application → run.

기본 조작: A/D 이동, S 웅크리기/발판 아래로, Space 점프, J 공격, Shift 대시, Q 1.2초 정신집중 후 자동 돌진 찌르기, E 상점/레버, I 인벤토리, 1/2 포션, Tab 지도(누르는 동안 정지), Esc 일시정지.

돌진 찌르기는 지상에서 사용합니다. 스킬 키나 화면 버튼을 1.2초 유지하면 4단계 집중 후 앞으로 돌진하며 찌릅니다. 집중 중에는 이동할 수 없고 일찍 놓으면 취소됩니다. 기본 피해는 전방 적 각각 20, 수정/검토용 재사용은 1초입니다. 스킬 전용 시각 효과/오디오는 없습니다. 최신 자세는 assets/art/hero.png를 사용합니다.

모든 캐릭터의 표시 크기와 몸/공격 판정 비율은 80%입니다. 플레이어 이동 340/초, 대시 960/초이며 돌진 찌르기는 돌진 0.22초·전체 동작 0.38초입니다. 이전 수치 변경 이력: docs/PACE_1103.md. 최신 수치: docs/TRAVERSAL_1104.md.

설정 → 키 설정에서 행동 키를 변경하고 저장할 수 있습니다. 상점 아이콘에는 현재 상호작용 키가 표시됩니다.

평상시/공격/집중/찌르기는 같은 가면 검객의 아틀라스와 공통 배율을 사용합니다. 이전 스프라이트 수정 기록은 docs/THRUST_IDENTITY_1104.md 및 docs/THRUST_ANATOMY_1104.md에 보존되어 있습니다.

최신 통합 내역과 검증 결과: CURRENT_VERSION.md.
